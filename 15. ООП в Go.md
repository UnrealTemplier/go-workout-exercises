# ООП в Go (Receivers, композиция, инкапсуляция, полиморфизм)

В этом файле собраны уникальные упражнения по теме **"ООП в Go (Receivers, композиция, инкапсуляция, полиморфизм)"**, отсортированные по возрастанию сложности.

Проверьте вызов методов на переменной этого типа. Объясните, почему нельзя объявлять методы для базовых типов (например, напрямую для `int`) или для типов из чужих пакетов.
