# Дженерики (Type parameters, constraints, generic-коллекции)

В этом файле собраны уникальные упражнения по теме **"Дженерики (Type parameters, constraints, generic-коллекции)"**, отсортированные по возрастанию сложности.

**Совет по изучению:**
* **В ООП:** Всегда задавайте себе вопрос: "Нужен ли здесь pointer receiver?". Если структура маленькая (например, пара `int`-ов или время) и не меняет своего состояния — используйте value receiver. Если структура большая или имеет мьютексы/файловые дескрипторы — только pointer receiver.
* **В Дженериках:** В Go есть негласное правило: "Не используйте дженерики, пока не почувствуете боль от их отсутствия". Сначала пишите код под конкретные типы (`int`, `string`), и только когда вам придется копипастить один и тот же алгоритм для разных типов — выносите его в дженерик-функцию. Излишняя абстракция в Go не приветствуется.
