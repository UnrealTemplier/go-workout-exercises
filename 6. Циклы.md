# Циклы (for, for-range)

В этом файле собраны уникальные упражнения по теме **"Циклы (for, for-range)"**, отсортированные по возрастанию сложности.

---

1. **Поиск простых чисел**: Напишите цикл, который находит все простые числа до N. Оптимизируйте его, прерывая внутренний цикл через `break`, когда делитель превышает квадратный корень из числа.

2. **Палиндром**: Напишите функцию, которая с помощью цикла (без использования `reverse`-слайсов) проверяет, является ли строка палиндромом, сравнивая символы с начала и с конца.

3. **Угадай число**: Сгенерируйте случайное число (пакет `math/rand`). В бесконечном цикле просите пользователя угадать, давая подсказки "больше" или "меньше", пока не угадает.

4. **Матрица (2D слайс)**: Создайте слайс слайсов (таблицу). С помощью вложенных циклов `range` выведите её в консоль в виде ровной сетки.

5. **Цикл `for` с тремя компонентами**: выведите все чётные числа от 1 до 20, используя `i += 2`.

6. **Бесконечный цикл с явным выходом**: `for { ... break }` – читайте ввод и выводите удвоенную строку, пока не будет введено `"exit"`.

7. **`for range` по срезу**: просуммируйте все элементы `[]int{10, 20, 30, 40}` и выведите сумму.

8. **Классический `for`**: Напиши цикл с инициализацией, условием и шагом (`for i := 1; i <= 10; i++`). Выведи числа от 1 до 10.

9. **`For` как `while`**: Опусти блок инициализации и шага. Напиши цикл, который начинается с `n := 1` и умножает `n` на 2, пока `n < 1000`. (Вывод степеней двойки).

10. **Классический цикл**: Напишите стандартный трехкомпонентный цикл `for` (инициализация; условие; шаг) для вывода чисел от 1 до 10.

11. **`for range` по `map`**: пройдите по `map[string]int{"a":1, "b":2}` и выведите ключ-значение.

12. Напиши программу с классическим `for` (C-style): `for i := 1; i <= 10; i++`. Выведи числа. Затем сделай обратный порядок (10 до 1) и с шагом 2.

13. **Бесконечный цикл**: Напиши `for { ... }`. Внутри запрашивай у пользователя ввод текста. Если он ввел "exit", прерви цикл с помощью `break`.

14. Напиши программу с `for` как **while**: `for condition { ... }`. Реализуй "угадай число": компьютер загадывает число (1–100), пользователь вводит варианты, цикл продолжается до угадывания.

15. **Обратный отсчет**: Напишите трехкомпонентный цикл `for`, который выводит числа от 10 до 1 в обратном порядке, а в конце выводит слово `"Старт!"`.

16. **`for range` по строке**: подсчитайте количество букв, цифр и пробелов в строке, используя `for _, r := range s`.

17. Напиши программу с **бесконечным циклом** `for { ... }` и `break` по условию. Читай ввод пользователя: если введено `"exit"` — выходи из цикла, иначе эхо-вывод строки.

18. **Таблица умножения**: С помощью двух вложенных циклов `for` выведите в консоль классическую таблицу умножения, форматируя вывод через `fmt.Printf` для ровных столбцов.

19. **Аналог цикла `while`**: В Go нет ключевого слова `while`. Напишите цикл `for`, содержащий только условие (например, `for x < 100`). Пусть внутри цикла переменная `x` умножается на 2 на каждой итерации.

20. **`break` и `continue`**: в цикле от 1 до 10 пропускайте (`continue`) нечётные числа и останавливайтесь (`break`), если встретили число 8.

    * *Для Go >= 1.22*: Проверьте, как изменилось поведение (теперь переменная пересоздается на каждой итерации).
