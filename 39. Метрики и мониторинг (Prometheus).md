1. **Базовый экспортер Prometheus**: Установите официальный клиент Prometheus для Go: `github.com/prometheus/client_golang/prometheus/promhttp` [417]. Напишите простой HTTP-сервер, который регистрирует обработчик по умолчанию для эндпоинта `/metrics` [417]. Запустите сервер, откройте страницу в браузере и изучите дефолтные метрики рантайма Go (выделение памяти, количество горутин, активность GC), которые клиент собирает автоматически.

3. **Метрика Counter (Счетчик)**: Создайте метрику типа Counter с поддержкой меток (labels) — `prometheus.NewCounterVec` [418]. Назовите её `http_requests_total` с метками `method` (метод запроса) и `status` (HTTP-статус ответа) [418]. Напишите HTTP-middleware, которое при каждом входящем запросе увеличивает счетчик на единицу с указанием конкретных меток (например, `method="POST"`, `status="201"`).

4. **Метрика Gauge (Измеритель)**: Метрика Gauge показывает текущее мгновенное значение, которое может как увеличиваться, так и уменьшаться. Создайте измеритель `active_websocket_connections` с помощью `prometheus.NewGauge` [419]. Напишите WebSocket-обработчик (из задач на WebSockets), который при подключении нового клиента вызывает `gauge.Inc()`, а при отключении — `gauge.Dec()` [419].

5. Подключите `github.com/prometheus/client_golang/prometheus` и создайте простейший **Counter**: `requests_total`. Инкрементируйте его при каждом HTTP-запросе.

6. Создайте **Histogram**: `http_request_duration_seconds` с бакетами `{0.005, 0.01, 0.025, 0.05, 0.1, 0.25, 0.5, 1, 2.5, 5}`. Записывайте latency каждого запроса.

7. Используйте **Labels** в метриках: `http_requests_total{method="GET", path="/api/users", status="200"}`. Изучите cardinality explosion (почему нельзя использовать user_id как label).

Напишите middleware, замеряющее время обработки входящего запроса, и записывайте длительность в гистограмму с помощью метода `Observe()`.

    * `redis_command_duration_seconds{command}`.
