# HTTP-клиент (Запросы, заголовки, парсинг JSON)

В этом файле собраны уникальные упражнения по теме **"HTTP-клиент (Запросы, заголовки, парсинг JSON)"**, отсортированные по возрастанию сложности.

---

1. Используй `http.Get`, чтобы сделать запрос к `https://golang.org`. Выведи статус-код ответа (например, 200 OK).

2. Прочитай тело ответа (Response Body) с помощью `io.ReadAll` и выведи первые 100 байт в консоль.

3. **[Каверзный кейс]**: Сделай 1000 запросов в цикле с помощью `http.Get`, но забудь закрыть тело ответа (`defer resp.Body.Close()`). Запусти программу и понаблюдай за ростом количества открытых файловых дескрипторов (утечка ресурсов). Исправь код, добавив `defer`.

4. Используй `net/url` для парсинга URL. Добавь query-параметры (например, `?q=golang&page=2`) с помощью `url.Values`.

5. Выполните POST-запрос, отправив JSON в теле. Не забудьте установить заголовок `Content-Type: application/json`.

6. Настрой кастомный `http.Client` с `Timeout: 5 * time.Second`. Сделай запрос к серверу, который отвечает дольше 5 секунд (можно использовать `httpbin.org/delay/10`). Поймай ошибку таймаута.

7. Создайте кастомный `http.Client` с настроенным таймаутом (`Timeout: 5 * time.Second`). Почему использование глобального `http.DefaultClient` в продакшене — плохая идея?

8. Настройте `http.Transport` для пулинга соединений (`MaxIdleConns`, `IdleConnTimeout`), чтобы переиспользовать TCP-соединения (Keep-Alive) и снижать нагрузку на сеть.

9. **Кастомный запрос (Custom Headers)**: Тебе нужно передать токен авторизации. Используй `req, err := http.NewRequest("GET", url, nil)`. Добавь заголовок: `req.Header.Set("Authorization", "Bearer my-token")`. Выполни запрос через `client.Do(req)`.

10. **[Каверзный кейс]**: Используй `context.WithTimeout` вместе с `http.NewRequestWithContext`. Отмени контекст вручную (`cancel()`) до истечения таймаута. Убедись, что запрос прерывается корректно.

11. **POST-запрос с JSON**: Закодируй структуру в JSON. Отправь POST-запрос на `https://jsonplaceholder.typicode.com/posts` с помощью `http.Post`. Укажи Content-Type `application/json`.

12. Реализуйте скачивание большого файла (например, видео или ISO-образа) с сохранением на диск через `io.Copy`, не загружая всё тело ответа в оперативную память.

13. **Смертельный грех — забытый Close**: Убедись, что в упр. 333 ты написал `defer resp.Body.Close()`. Без этого соединения не возвращаются в пул, и программа со временем падает от нехватки памяти или файловых дескрипторов. Вызывай `Close()` всегда, даже если читаешь не всё!

14. Загрузите файл на сервер, используя `multipart/form-data` (пакет `mime/multipart` и `http.NewRequest`).

15. **Таймаут клиента**: Глобальный `http.Get` не имеет таймаута (он может висеть вечно). Создай свой клиент: `client := &http.Client{Timeout: 3 * time.Second}`. Сделай запрос через `client.Get(...)`.

16. Изучите работу с Cookie: прочитайте `Set-Cookie` из ответа и отправьте их обратно в следующем запросе через `http.CookieJar`.

17. Реализуйте HTTP-клиент с автоматическим ретраем (повторной попыткой) при получении статус-кодов 5xx или сетевых ошибок (используйте экспоненциальную задержку и `context`).

18. **Базовый GET-запрос**: Напишите программу, которая выполняет GET-запрос к публичному тестовому API (например, `https://jsonplaceholder.typicode.com/posts/1`) с помощью `http.Get`. Считайте тело ответа, преобразуйте его в строку и выведите в консоль.

19. **Query-параметры**: Не клей URL руками (как `?name=Ivan&age=20`). Используй `url.Values{}`. Добавь параметры, затем приклей их к запросу: `req.URL.RawQuery = q.Encode()`.

20. **Потоковый парсинг JSON**: Вместо того чтобы выгружать весь ответ в память через `io.ReadAll`, распарси JSON прямо из потока: `json.NewDecoder(resp.Body).Decode(&myStruct)`. Это сэкономит кучу оперативной памяти при больших ответах.

21. **Скачивание файла**: Сделай GET-запрос к любой картинке в интернете. Создай пустой файл `os.Create("image.jpg")`. Перекачай данные напрямую без загрузки в память: `io.Copy(file, resp.Body)`.

22. **Подводный камень: Утечка соединений**: Измените предыдущую программу так, чтобы она выполняла 1000 GET-запросов в цикле. Забудьте вызвать `resp.Body.Close()`. Посмотрите, как программа быстро исчерпывает лимит открытых дескрипторов файлов ОС и падает. Напишите правильный вариант с `defer resp.Body.Close()` сразу после проверки на ошибку.

23. **Тонкая настройка пула соединений (Transport)**: Создай свой `http.Transport` с параметром `MaxIdleConnsPerHost: 100`. Передай его в `http.Client`. Полезно для высоконагруженных сервисов, делающих сотни запросов к одному API.

28. **Опасность `http.DefaultClient`**: Напишите комментарий-объяснение, почему использование стандартного `http.Get` или `http.DefaultClient` крайне опасно на высоконагруженном продакшене (подсказка: отсутствие таймаутов по умолчанию может привести к зависанию горутин при сетевых сбоях). Напишите код инициализации безопасного клиента `http.Client` с жестким таймаутом в 3 секунды.

Отправьте POST-запрос на тестовый URL с помощью `http.Post` или создав кастомный запрос через `http.NewRequest`. Убедитесь, что вы правильно установили заголовок `Content-Type: application/json`.

30. **Параметры запроса и заголовки**: Напишите программу, которая выполняет запрос, добавляя кастомные HTTP-заголовки (например, `Authorization: Bearer my_token`) и Query-параметры (например, `?page=2&limit=10`). Для сборки URL с параметрами используйте структуру `net/url` и её методы.

31. **Обработка ошибок и статус-кодов**: Выполните запрос к несуществующему домену и обработайте возникающую сетевую ошибку. Выполните запрос к существующему домену, но по некорректному адресу (чтобы получить статус `404 Not Found`). Напишите корректную обработку статус-кодов ответов (проверку `resp.StatusCode`).

32. Напиши простой HTTP-клиент: `resp, err := http.Get("https://api.github.com/users/golang")`. Прочитай `resp.Body`, декодируй JSON в структуру. Не забудь `defer resp.Body.Close()`.

33. Покажи **утечку соединений**, если забыть `resp.Body.Close()`. Запусти 10000 запросов без закрытия — получи `"too many open files"`. Исправь: всегда закрывай Body, даже если не читаешь (или используй `io.Copy(io.Discard, resp.Body)`).

Данный транспорт должен перехватывать все исходящие запросы вашего клиента, автоматически замерять время их выполнения и выводить его в лог, после чего делегировать выполнение стандартному транспорту `http.DefaultTransport`.
