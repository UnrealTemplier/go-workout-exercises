# Компиляция, сборка и запуск Go-программ

В этом файле собраны уникальные упражнения по теме **"Компиляция, сборка и запуск Go-программ"**, отсортированные по возрастанию сложности.

---

1. Установи Go (если еще не установлен). Выведи версию Go в консоль с помощью команды `go version`.

2. Создайте файл `main.go`, напишите простейшую программу "Hello, World!" и запустите её командой `go run`.

3. Скомпилируйте ту же программу командой `go build` и запустите полученный бинарник.

4. **Компиляция исполняемого файла**: Скомпилируйте ваш проект `hello_mod` с помощью команды `go build`. Найдите появившийся исполняемый файл (бинарник) в директории и запустите его из консоли напрямую (например, `./hello_mod` или `hello_mod.exe`).

5. **Кросс-компиляция**: Скомпилируй свою программу для другой операционной системы (например, если ты на Windows, скомпилируй под Linux, используя переменные `GOOS` и `GOARCH`).

6. Скомпилируй программу в бинарный файл с помощью `go build`. Запусти полученный исполняемый файл напрямую из консоли.

7. **Установка в систему**: Используйте команду `go install`. Найдите, куда Go сохранил скомпилированный бинарный файл (проверьте директорию `$GOPATH/bin` или `$HOME/go/bin`). Попробуйте вызвать программу из консоли из любой другой директории.

8. Установи программу в системный `$GOPATH/bin` с помощью `go install`. Проверь, что она запускается из любой директории.

9. Используй команду `go build -o myapp` для задания кастомного имени бинарнику. Запусти его.

10. Отформатируй свой код с помощью `go fmt ./...`.

11. **Кросс-компиляция**: Находясь на своей текущей операционной системе, скомпилируйте исполняемый файл для другой ОС (например, если вы на Windows, скомпилируйте для Linux с помощью команды `GOOS=linux GOARCH=amd64 go build`, или наоборот). Убедитесь, что создался файл другого формата.

12. Изучи флаг `-race`. Напиши простейшую программу с горутинами (можно подсмотреть в инете) и запусти её с флагом `go run -race main.go`.

13. Проверь свой код на ошибки и неправильные паттерны с помощью `go vet ./...`.

14. Соберите кросс-компиляцией бинарники для Windows и Linux с помощью `GOOS` и `GOARCH`.

15. Напиши программу, в которой будет функция `init()`, выводящая "Init started", и функция `main()`, выводящая "Main started". Проверь порядок вызова.

16. Создай два файла в одном пакете `main`: `main.go` и `utils.go`. В `utils.go` напиши функцию `SayHi()`, а в `main.go` вызови её. Убедись, что `go build` работает.

17. Попробуй объявить две функции `main` в разных файлах одного пакета. Посмотри на ошибку компиляции.

18. **Сборка с флагами**: Скомпилируй программу с флагом `-ldflags="-s -w"`, чтобы удалить отладочную информацию. Сравни размер полученного бинарника с обычным.

---

19. Напиши программу с флагами командной строки (`flag` package). Реализуй: `--name` (string), `--age` (int), `--verbose` (bool). Запусти с разными комбинациями флагов.

20. Реализуй подкоманду через `flag`: `app add --x 5 --y 3` → 8, `app sub --x 5 --y 3` → 2. Используй `flag.NewFlagSet`.

21. Вставь в бинарник информацию о версии через `-ldflags`: `-X main.Version=1.2.3 -X main.BuildTime=$(date)`. Выведи эти переменные при запуске.

22. Скомпилируй программу с race detector: `go run -race`. Создай data race (два горутины пишут в одну переменную без синхронизации). Запусти с `-race` и без него, сравни поведение.

23. Создай программу с graceful shutdown: перехватывай сигналы `os.Interrupt`, `syscall.SIGTERM`. При получении сигнала — выведи сообщение и корректно завершись.

24. Напиши скрипт на bash/powershell, который: компилирует Go-программу, запускает тесты, проверяет форматирование (`go fmt`), запускает линтер (`golangci-lint` или `go vet`).

25. Создай Docker-контейнер для Go-приложения (multi-stage build). Первый этап — сборка, второй — минимальный образ `scratch` или `alpine` с бинарником.
