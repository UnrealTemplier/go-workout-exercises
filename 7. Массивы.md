# Массивы (Arrays)

В этом файле собраны уникальные упражнения по теме **"Массивы (Arrays)"**, отсортированные по возрастанию сложности.

---

1. **Инициализация массива**: Объявите массив из 5 элементов типа `int`. Инициализируйте его тремя способами: по умолчанию (zero values), явным списком значений в литерале, и с помощью синтаксиса многоточия `[...]int{...}`.

2. Объяви массив `[5]int`, заполни его значениями `{10, 20, 30, 40, 50}`. Выведи длину через `len` и каждый элемент по индексу.

3. Объявите массив из 5 целых чисел, не инициализируя его. Выведите значения по умолчанию (zero values).

4. Объяви массив из 5 целых чисел. Выведи его. Выведи его длину с помощью `len()`.

5. Создайте массив из 7 чисел, найдите сумму и произведение всех элементов.

6. **Значимая семантика массива**: Создай `a := [3]int{1, 2, 3}`. Присвой `b := a`. Измени `b[0]`. Выведи оба массива и убедись, что массивы в Go копируются **целиком**.

7. Объяви массив строк `[3]string{"Go", "Rust", "C++"}`. Обрати внимание на вывод типа.

8. Напиши функцию `SumArray(arr [5]int) int`, которая суммирует элементы массива. Внутри функции измени `arr[0] = 999`. В `main` выведи оригинальный массив до и после вызова — покажи, что массив передался **по значению** (полная копия).

9. **Сравнение массивов**: Создайте два массива `[3]int{1, 2, 3}` и `[3]int{1, 2, 3}`. Сравните их через оператор `==`. Создайте третий массив `[4]int{1, 2, 3, 4}`. Попробуйте сравнить его с первым массивом и разберитесь, почему компилятор выдает ошибку (разные типы данных).

10. Проверьте, является ли массив палиндромом (читается одинаково слева направо и справа налево).

11. Создай многомерный массив `[3][4]int` (матрица 3×4). Заполни его вложенными циклами значениями `i*10 + j`. Выведи в виде отформатированной таблицы.

12. Используй синтаксис `[...]int{10, 20, 30}`. Выведи длину массива.

13. Сравни два массива `[3]int` через операторы `==` и `!=`. Затем попробуй сравнить `[3]int` и `[4]int` — получи ошибку компиляции. Объясни, почему массивы comparable, но только при одинаковой длине.

14. Напишите функцию, принимающую массив `[3]int`. Попробуйте передать ей массив `[4]int` и изучите ошибку компилятора (размер массива — часть его типа).

15. **Матрицы (Двумерные массивы)**: Создайте матрицу `[3][3]int` (таблицу 3x3). Заполните её числами от 1 до 9. Напишите вложенные циклы для вывода матрицы в консоль в виде красивой таблицы.

16. Создайте двумерный массив (матрицу) 3x3 и заполните его числами от 1 до 9 с помощью вложенных циклов.

17. Передайте массив в функцию для модификации (удвоить каждый элемент). Убедитесь, что исходный массив не изменился.

18. Объяви двумерный массив матрицы 3x3, заполненный нулями. Выведи его.

19. Напиши программу, которая демонстрирует **zero value** массива: объяви `var arr [5]int` без инициализации. Выведи — все элементы будут нулевыми.

20. **Передача массива в функцию**: Напишите функцию `DoubleArray(arr [5]int)`, которая удваивает каждый элемент массива. Передайте туда массив, выведите его до и после вызова функции. Убедитесь, что исходный массив снаружи не изменился. Перепишите функцию так, чтобы она принимала указатель на массив `*[5]int`, и добейтесь изменения исходного массива.

21. Создай массив `[3]*int` (массив указателей). Заполни его адресами трёх переменных. Измени значения через массив. Покажи, что массив хранит указатели, а не сами значения.

---

22. Напишите программу, которая находит сумму элементов массива, используя классический цикл `for` с индексом, без использования `range`.

23. Напиши функцию, которая принимает массив `[5]int` и изменяет его первый элемент. Выведи массив после вызова функции (убедись, что оригинал не изменился — передача по значению).

24. **Размер массива в памяти**: С помощью функции `unsafe.Sizeof` из пакета `unsafe` выведите размер в байтах для массивов `[10]int8`, `[10]int32` и `[10]int64`. Объясните разницу.

25. Передайте массив в функцию по значению и измените его элемент внутри. Убедитесь, что оригинальный массив в `main` остался прежним.

26. Отсортируйте массив строк по длине, используя ручную реализацию пузырьковой сортировки.

27. Используй `for range` для итерации по массиву. Выведи индекс и значение.

28. **Поиск экстремумов**: Заполните массив `[10]int` случайными числами. Напишите алгоритм, который находит минимальное и максимальное значения в этом массиве за один проход цикла.

29. Используйте `unsafe.Sizeof` и `unsafe.Alignof`, чтобы изучить, сколько памяти занимает массив из 100 элементов `int64` и как он располагается в памяти.

30. Используйте массив как ключ в map: создайте `map[[3]int]string`, где ключ — RGB-тройка, а значение — название цвета.

31. **Разворот на месте (In-place reverse)**: Напишите функцию, которая принимает указатель на массив `[8]string` и разворачивает его элементы в обратном порядке без выделения памяти под новый массив.

32. **Выход за границы**: Создайте массив `arr [3]int`. Попробуйте обратиться к `arr[5]` напрямую. Посмотрите на ошибку компиляции. Теперь создайте переменную `index := 5` и попробуйте обратиться к `arr[index]`. Запустите программу и разберитесь, почему в этом случае происходит паника во время выполнения (runtime panic), а не ошибка компиляции.
