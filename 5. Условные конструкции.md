# Условные конструкции (if, switch)

В этом файле собраны уникальные упражнения по теме **"Условные конструкции (if, switch)"**, отсортированные по возрастанию сложности.

---

1. Напиши программу, которая читает целое число из консоли и сообщает: положительное оно, отрицательное или ноль. Используй конструкцию `if / else if / else`.

2. **Базовый `if-else`**: Считай из консоли число. Напиши проверку: если оно четное, выведи "Четное", иначе "Нечетное" (используй оператор остатка от деления `%`).

3. **Базовый `if-else`**: Напишите программу, которая запрашивает у пользователя целое число и выводит в консоль, является ли оно четным или нечетным.

4. **Простое условие**: запросите у пользователя целое число и выведите `Even` / `Odd` через `if-else`.

5. Напиши программу с **if с инициализацией**: `if x := rand.Intn(100); x > 50 { ... }`. Покажи, что переменная `x` недоступна за пределами блока `if`. Попробуй обратиться к ней ниже — получи ошибку компиляции.

6. **Каскадный `if`**: Считай возраст пользователя. Напиши цепочку `if - else if - else`, которая выводит: 0-12 (ребенок), 13-17 (подросток), 18-59 (взрослый), 60+ (пенсионер).

7. **Множественные ветвления**: Напишите программу, определяющую оценку студента по 100-балльной шкале: 90+ — "A", 80-89 — "B", 70-79 — "C", 50-69 — "D", меньше 50 — "F". Используйте цепочку `if - else if - else`.

8. **`if` с коротким объявлением**: внутри условия объявите переменную `age := ...` и используйте её только в блоках `if/else if/else`.

9. Напиши функцию `Divide(a, b float64) (float64, error)` и вызывай её через **idiomatic if**: `if result, err := Divide(x, y); err != nil { ... } else { fmt.Println(result) }`. Объясни, почему в Go принят именно такой стиль обработки ошибок.

10. **`If` с инициализацией (Критически важно!)**: Напиши вызов функции, которая возвращает значение и ошибку (например, `strconv.Atoi("123")`). Сделай вызов и проверку ошибки прямо в заголовке `if`: `if val, err := strconv.Atoi(...); err != nil { ... }`.

11. **Инициализация внутри `if`**: Напишите условную конструкцию с краткой инициализацией переменной: `if x := getSomeValue(); x > limit { ... }`. Попробуйте обратиться к переменной `x` вне этого блока `if-else`. Зафиксируйте ошибку компиляции и сделайте вывод о границах видимости (scope) такой переменной.

12. **Цепочка `if-else if-else`**: переведите числовую оценку (0–100) в буквенную (A, B, C, D, F) с несколькими ветками.

13. **Теневое копирование (Shadowing) в `if`**: Объяви `x := 10` до `if`. Затем напиши `if x := 5; x > 0 { fmt.Println(x) }`. Выведи `x` после `if`. Пойми, почему внутри `if` была 5, а снаружи осталась 10.

14. Напиши программу, которая по дню и месяцу рождения определяет **знак зодиака**. Используй длинную цепочку `if / else if`. Затем перепиши ту же логику через `switch` без тега (tagless switch) и сравни читаемость.

15. Напиши программу, которая определяет **високосный год**. Условие: делится на 4, но не делится на 100, либо делится на 400. Используй логические операторы `&&` и `||`.

16. **Булевы упрощения**: Создайте переменную `isValid bool = true`. Напишите условие `if`, проверяющее её значение. Избегайте явного сравнения вида `if isValid == true` — напишите идиоматичный для Go вариант.

17. **Классический `switch`**: напишите `switch` для дня недели (1–7) и выведите название дня.

18. **Базовый `switch` по значению**: Напишите программу, которая принимает число от 1 до 7 (день недели) и с помощью конструкции `switch` выводит название этого дня (например, 1 — "Понедельник"). Добавьте ветку `default` для обработки некорректных чисел.

19. Напиши программу с `switch` по **строке**: принимает команду (`"start"`, `"stop"`, `"restart"`, `"status"`) и выполняет соответствующее действие (просто выводит сообщение). Добавь `default` для неизвестной команды.

20. **Базовый `switch`**: Запроси у пользователя номер дня недели (1-7) и выведи его название через `switch`. Обработай `default` случай (если введено другое число).

21. **`switch` без выражения**: превратите предыдущий пример в `switch { case day == 1: ... }` (true switch).

22. Напиши программу с **tagless switch** (switch true): проверяет диапазон возраста и выводит категорию (`"ребёнок"`, `"подросток"`, `"взрослый"`, `"пенсионер"`). Используй сравнения в `case`.

23. **Множественный `case`**: Перепиши упр. 117 так, чтобы на дни 1,2,3,4,5 программа выводила "Будний день", а на 6,7 — "Выходной", объединив значения через запятую в одном `case`.

24. Напиши программу с `switch` и `fallthrough`: по номеру месяца определяет сезон. Используй `fallthrough` для группировки месяцев в сезоны (например, декабрь → зима, но fallthrough в январь? Нет, сгруппируй case'ы: `case 12, 1, 2:`). Затем сделай версию с `fallthrough`, где каждый case "проваливается" в следующий для накопления описания.

25. **Множественные значения в `case`**: Перепишите предыдущую программу с днями недели так, чтобы `switch` группировал дни: в одном `case` перечислялись будни (1, 2, 3, 4, 5) и выводилось "Будний день", а в другом — выходные (6, 7) с выводом "Выходной".

26. **Несколько значений в `case`**: определите выходной или будний день через `case 6, 7:`.

27. Напиши программу с **type switch**: функция принимает `interface{}` (или `any`) и определяет тип значения (`int`, `string`, `bool`, `float64`). Для каждого типа выводит сообщение с форматированным значением. Добавь `default`.

28. **`Switch` без выражения (аналог каскадного if)**: Перепиши упр. 113 (возрастные категории), используя конструкцию `switch { case age < 13: ... }` (без передачи переменной после слова `switch`).

29. **`switch` без выражения (Tagless switch)**: Напишите аналог цепочки `if-else` из задачи на определение оценки по баллам, используя `switch` без указания переменной после ключевого слова (когда условия пишутся прямо в ветках `case`, например, `case score >= 90:`).

30. **`fallthrough`**: продемонстрируйте, как `fallthrough` передаёт управление следующему `case`, и объясните, зачем это нужно.

31. Напиши программу с type switch, где в каждом `case` извлекается значение с тем же именем переменной: `case int: fmt.Println(v * 2)`. Покажи, что переменная `v` в каждом case имеет тип конкретного case'а.

32. **Провал проваливания (`fallthrough`)**: В Go, в отличие от C/Java/JS, `switch` не требует `break` — он выходит автоматически. Попробуй использовать ключевое слово `fallthrough` в конце одного из `case`, чтобы заставить программу выполнить следующий `case` независимо от его условия.

33. Напиши программу, которая имитирует **тернарный оператор** через `if / else`. В Go нет `?:` — объясни, почему (философия языка: явность лучше краткости). Напиши функцию `Max(a, b int) int` без тернарного оператора.

34. **Эффект `fallthrough`**: Создайте `switch` по целому числу от 1 до 3. В ветках `case 1` и `case 2` добавьте ключевое слово `fallthrough`. Запустите программу, передав на вход `1`, и проанализируйте, почему выполнился код всех последующих веток.

35. **`type switch`**: создайте несколько переменных разных типов, присвойте их `interface{}` и внутри `switch v := x.(type)` выведите название типа.

36. **`Switch` с инициализацией**: По аналогии с `if`, проинициализируй переменную прямо в конструкции `switch` (`switch num := getNumber(); num { ... }`).

37. Напиши программу с **вложенными if** (3 уровня вложенности): проверка доступа к системе (активен ли пользователь, есть ли права админа, не истёк ли срок действия). Затем перепиши через **guard clauses** (ранние `return`) — сравни читаемость.

38. **Принудительный выход из `switch`**: Напишите `switch`, проверяющий тип операции (например, строка `"sum"`). Внутри одной из веток `case` добавьте условие: если дополнительный параметр равен нулю, прервать выполнение этой ветки досрочно с помощью `break`, не выполняя оставшуюся часть кода в этом `case`.

39. **Паттерн "Guard Clauses" (Ранний возврат)**: Напиши функцию с глубокой вложенностью (`if a { if b { if c { return true } } }`). Перепиши её в "плоском" стиле, инвертируя условия и используя `return` для раннего выхода (`if !a { return false }`). Это золотой стандарт чистого кода в Go.

Покажи short-circuit evaluation: создай функции-предикаты с `fmt.Println` внутри и убедись, что при `false` в левой части `&&` правая часть не вычисляется.
