# AGENTS.md — Руководство для ИИ-агентов по генерации глав учебника Go

Данный файл является исчерпывающим стандартом и инструкцией для ИИ-агентов (Antigravity, Claude, ChatGPT, Cursor и др.) по разработке, расширению и поддержке интерактивного учебника-тренажера по языку **Go (Golang)**.

---

## 🎯 1. Цель проекта и Целевая аудитория

* **Цель проекта:** Создать полноценный, интерактивный, глубокий веб-учебник на русском языке, состоящий из **83 глав** (соответствующих 83 markdown-файлам с упражнениями в корне репозитория `/home/ut/work/go-workout/`).
* **Целевая аудитория:** Уверенно-начинающие бэкенд-разработчики с базовым опытом в C/C++, Python, PHP или JS, изучающие Go для трудоустройства на позиции Middle Go Developer в ведущие российские технологические компании и BigTech (**Яндекс, Ozon, Авито, Т-Банк, VK, Wildberries**).
* **Стиль изложения:** Живой, структурированный, инженерно-строгий, с глубоким погружением в механику компилятора, рантайма (GMP, GC, epoll, аллокатор памяти), сетевого стека, конкурентности и лучших практик DevSecOps/Kubernetes.

---

## 🏗 2. Архитектура генератора учебника (`builder/`)

Все главы генерируются модульным скриптом на Python в директории `builder/`:

```text
/home/ut/work/go-workout/
├── index.html                    # Глава 01 (Пакеты и модули — 91 упр.)
├── chapter2.html                 # Глава 02 (Компиляция и сборка — 25 упр.)
├── chapter3.html                 # Глава 03 (генерируется следующей)
├── AGENTS.md                     # Данный файл инструкций
├── 1. Пакеты и модули.md        # Исходный задачник главы 1
├── 2. Компиляция, сборка...md   # Исходный задачник главы 2
├── ...                           # Markdown-файлы задачников до главы 83
└── builder/
    ├── chapters.py               # Динамическое сканирование всех 83 markdown-файлов
    ├── template.py               # Reusable HTML-шаблоны, CSS, JS и CDN Prism.js
    ├── build_all.py              # Главный сборочный скрипт всех HTML-страниц
    ├── audit_all.py              # Автоматический валидатор синтаксиса и структуры
    └── chapterX_data.json        # Структурированные данные упражнений главы X
```

## 📋 3. Пошаговый пайплайн генерации новой главы

Когда пользователь просит сгенерировать следующую главу (например, `N. Название.md`):

### Шаг 1: Анализ исходного файла
1. Прочитать файл `N. <Тема>.md` с помощью инструмента чтения файлов.
2. Подсчитать точное количество упражнений и составить их список (номера от 1 до $K$).
3. **КРИТИЧЕСКОЕ ПРАВИЛО:** Не пропускать ни одного упражнения! Каждое упражнение из markdown-файла обязано быть полностью решено и подробно разобрано.

### Шаг 2: Генерация датасета упражнений (`builder/chapterN_data.json`)
Каждое упражнение обязано содержать 7 обязательных разделов в JSON-структуре:

```json
{
  "num": 1,
  "title": "Краткий емкий заголовок темы",
  "task": "Оригинальный текст условия задачи из markdown-файла",
  "theory": "Теоретический фундамент: концепция, сравнение с C++/Python/JS, стандарты Go 1.22+",
  "step_by_step": "Пошаговый ход мысли инженера, порядок действий в терминале и IDE",
  "code_blocks": [
    {
      "filename": "main.go (или команда терминала)",
      "lang": "go",
      "code": "Полный рабочий компилируемый код без псевдокода",
      "note": "Пояснение к листингу"
    }
  ],
  "under_the_hood": "Низкоуровневая механика: как это устроено в компиляторе (AST/SSA), линкере, рантайме или ОС",
  "pitfalls": "Частые ошибки новичков, ловушки, утечки памяти, гонки данных",
  "bigtech_interview": "Вопрос с собеседования в BigTech по данной теме и эталонный ответ"
}
```

> **Совет по генерации данных:** Во избежание синтаксических ошибок экранирования кавычек в Bash/Python, сохраняйте упражнения через Python-скрипт с `json.dump(..., ensure_ascii=False, indent=2)`.

### Шаг 3: Обновление сборочного конвейера (`builder/build_all.py`)
1. Подключить `chapterN_data.json` в `builder/build_all.py`.
2. Создать функцию `build_chapterN_html(chapters)` с Hero-блоком, статистикой, секционными разделителями и карточками упражнений.
3. Обновить `build_sidebar()`:
   - Добавить ссылку на новую главу `chapterN.html` со статусом `K/K`.
   - Если глава активна, прикрепить `id="active-chapter-toggle"` и выпадающий блок `<div class="sub-exercises-list" id="active-sub-exercises">` со ссылками `#ex-1` ... `#ex-K`.
4. Сгенерировать файл `chapterN.html` и **пересобрать все предыдущие страницы** (`index.html`, `chapter2.html`, etc.), чтобы сайдбар и взаимные ссылки были синхронизированы на всех страницах.

### Шаг 4: Обязательный финальный технический аудит (`builder/audit_all.py`)
Перед отправкой ответа пользователю **всегда запускать валидационный скрипт**:
1. Проверка синтаксиса всего Go-кода через `gofmt -e`.
2. Проверка наличия всех HTML-якорей `#ex-1` ... `#ex-K`.
3. Проверка логической строгости (обработка ошибок, потокобезопасность, контексты).

## 🎨 4. Стандарты дизайна, UI и верстки

* **Цветовая палитра (Dark Theme):**
  - Фон страницы: `#090d16` (глубокий темный)
  - Поверхности/сайдбар: `#0f172a`
  - Карточки упражнений: `#131d33` (бордер `#1e293b`, hover `#334155`)
  - Акцентный цвет Go: `#00ADD8` (Go Cyan) / `#38bdf8`
  - Статус "Готово": `rgba(16, 185, 129, 0.15)` (`#34d399`)
* **Типографика:**
  - Основной текст: шрифт **Roboto** (400, 500, 700)
  - Код и терминал: шрифт **Cascadia Code** / **Roboto Mono**
* **Подсветка синтаксиса:** Prism.js Tomorrow Dark (`prism-go`, `prism-bash`, `prism-json`, `prism-makefile`).
* **Интерактивные элементы:**
  - Кнопка «Копировать» у каждого блока кода (с переключением на «Скопировано!» на 1.8 сек).
  - Полоса прогресса чтения в самом верху окна (`#progress-bar`).
  - Плавающая кнопка возврата наверх (`#back-to-top`).
  - Живой поиск по темам и упражнениям (`#search-input`).

## ⚠️ 5. Ошибки, грабли и правила (Чего НЕЛЬЗЯ делать)

На основе опыта разработки первых глав зафиксированы строгие правила:

| ❌ Как НЕЛЬЗЯ делать | ✅ Как НАДО делать | Причина / Обоснование |
| :--- | :--- | :--- |
| **Добавлять шевроны `▼`/`▶` в заголовок активного модуля** | Заголовок модуля в сайдбаре должен быть **чистым текстом** `<span><strong>N. Название</strong></span>` | Любые иконки перед текстом смещают выравнивание, и заголовок начинает визуально «прыгать» по сравнению с другими главами. |
| **Скроллить страницу при клике на заголовок в сайдбаре** | Использовать `e.preventDefault()` и `e.stopPropagation()` в JS, переключая только CSS-класс `.collapsed` у `.sub-exercises-list`. | Пользователь кликает по модулю в сайдбаре только для управления меню, основной контент справа не должен дергаться. |
| **Оставлять подсписок свернутым при поиске** | При вводе текста в `#search-input` JS обязан автоматически снять класс `collapsed`, если он был установлен. | Иначе отфильтрованные поиском упражнения останутся невидимыми внутри скрытого аккордеона. |
| **Писать псевдокод вида `// ... здесь логика`** | Писать **полный, самодостаточный, рабочий код** с импортами и обработкой ошибок. | Учебник ориентирован на практику; разработчик должен иметь возможность скопировать код и сразу запустить его в терминале. |
| **Игнорировать `if err != nil`** | Всегда явно обрабатывать ошибки через `fmt.Errorf`, логирование или возврат. | В Go и на собеседованиях в BigTech пропуск проверки ошибок считается критическим антипаттерном. |
| **Создавать канал сигналов без буфера `make(chan os.Signal)`** | Всегда создавать `make(chan os.Signal, 1)`. | Небуферизированный канал может потерять сигнал ОС (`SIGINT`/`SIGTERM`), если горутина не успела встать на чтение. |
| **Забывать `-s -w` или `CGO_ENABLED=0` при кросс-компиляции/Docker** | В продакшен-сборках указывать `CGO_ENABLED=0 go build -ldflags="-s -w"`. | Гарантирует 100% статический бинарник без зависимостей от libc хоста и минимальный размер Docker-образа (10–15 МБ на `FROM scratch`). |

## 🚀 6. Быстрый шаблон промпта для ИИ

Если вы передаете задачу следующему агенту, используйте данный шаблон:

```text
Сгенерируй главу N учебника по файлу "N. <Название>.md" строго в соответствии с инструкциями в AGENTS.md.
1. Прочитай файл "N. <Название>.md" и извлеки все упражнения без исключения.
2. Создай builder/chapterN_data.json со всеми 7 обязательными блоками для каждого упражнения.
3. Обнови builder/build_all.py и пересобери все страницы (index.html, chapter2.html, ..., chapterN.html).
4. Проведи финальную проверку через builder/audit_all.py (синтаксис Go, наличие всех якорей #ex-*, логика).
```
