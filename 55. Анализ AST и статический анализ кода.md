# Анализ AST и статический анализ кода

В этом файле собраны уникальные упражнения по теме **"Анализ AST и статический анализ кода"**, отсортированные по возрастанию сложности.

---

1. **Базовый парсинг.**: Напишите программу, которая принимает `.go`-файл, парсит его через `go/parser.ParseFile` и выводит все top-level объявления: `FuncDecl`, `GenDecl` (type, var, const, import). Объясните, что такое `*ast.File` и `*token.FileSet`.

2. **Токенизация (`go/scanner`)**: Создай строку с Go-кодом `src := "package main; func main() { println(42) }"`. Используй `scanner.Scanner`, чтобы разбить текст на токены. В цикле выведи каждый токен (названия вроде `IDENT`, `LPAREN`, `INT`) и его позицию (строка/колонка).

3. **Обход AST.**: Используя `ast.Inspect`, найдите все `CallExpr` в файле и выведите имя вызываемой функции. Объясните разницу между `ast.Inspect` (функция-замыкание) и `ast.Walk` (интерфейс `Visitor`).

4. **Парсинг Go-файла в AST**: Создайте файл `target.go` с простым кодом (объявление структуры, пара функций). Напишите парсер, который с помощью пакетов `go/parser` [523] и `go/token` [523] разбирает этот файл в синтаксическое дерево `*ast.File` [523]. Выведите структуру дерева на экран в виде красивого форматированного текста с помощью функции `ast.Print` [523].

5. Напиши программу, которая читает `.go` файл, использует `parser.ParseFile` для получения AST-дерева. Выведи дерево в консоль с помощью `ast.Print(fset, tree)`.

6. **Парсинг файла (`go/parser`)**: Используй `parser.ParseFile`, чтобы распарсить простой файл `main.go`. Полученный объект `*ast.File` выведи в консоль через функцию `ast.Print(fset, node)`. Изучи гигантское дерево, которое генерирует компилятор.

7. **Позиции и токены.**: Напишите инструмент, который для каждого `ast.Ident` выводит его позицию в файле (`token.Pos` → `fset.Position`). Объясните, почему `Pos` — это смещение в `FileSet`, а не строка/колонка напрямую.

8. Используй `ast.Inspect(tree, func(n ast.Node) bool { ... })`, чтобы найти все узлы типа `*ast.FuncDecl` (объявления функций). Выведи имена всех функций в файле.

9. **Простой линтер: запрет `fmt.Println`.**: Напишите анализатор, который находит вызовы `fmt.Println` (или `log.Println`) в коде и выдаёт предупреждение. Используйте `go/ast` без `go/analysis`. Объясните, как различить `fmt.Println` от `myfmt.Println` через селектор (`ast.SelectorExpr`).
