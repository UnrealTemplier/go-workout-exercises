# Указатели и работа с памятью

В этом файле собраны уникальные упражнения по теме **"Указатели и работа с памятью"**, отсортированные по возрастанию сложности.

---

1. Сравните работу оператора `new` и взятия адреса от литерала `&struct{}` для создания указателей на структуры.

2. Измените элементы среза внутри функции, затем выполните `append` внутри функции. Верните срез или используйте указатель на срез — разберите разницу в поведении.

3. Создайте массив, получите указатель на него и попробуйте изменить элементы через указатель.

4. Создайте переменную, получите её адрес с помощью `&`, сохраните его в указатель и выведите значение указателя и значение по адресу (`*`).

5. Создайте структуру `User` с полями `Name` и `Age`. Создайте указатель на неё и измените поля, используя как оператор `.`, так и разыменование `(*u).Name`.

6. Используйте указатель на структуру, обратитесь к полям без явного разыменования (`ptr.Name`).

7. Создай указатель `p`, который хранит адрес `x`. Выведи значение по этому указателю (`*p`).

8. Напиши функцию `ClearSlice(s *[]int)`, которая принимает указатель на слайс и делает `*s = (*s)[:0]`. Покажи, что теперь оригинал изменился.

9. Напишите функцию, которая возвращает указатель на локальную переменную функции. Убедитесь, что Go корректно обрабатывает это (escape analysis).

10. Создайте переменные через `new(int)` и `&int{}` (для структур `&Person{}`), объясните разницу.

11. Изучите, как работает `nil`-указатель: создайте указатель на структуру, не инициализируйте его и попробуйте обратиться к полю (поймайте panic).

12. Реализуйте функцию, принимающую `**int`, выделите память и измените внешний указатель.

13. Объяви указатель на `int` без начального значения. Выведи его (должен быть `<nil>`).

14. Функция, принимающая `*int`, должна изменить сам указатель на другую переменную — понадобится `**int`.

15. Попробуй разыменовать `nil`-указатель. Поймай панику.

16. Напишите функцию, возвращающую указатель на локальную переменную (побег в кучу), и проверьте работоспособность.

17. Создайте указатель на указатель (`**int`), измените значение оригинальной переменной через двойное разыменование.

18. Проверьте указатель на `nil` перед разыменованием; реализуйте безопасную функцию получения значения по указателю.

19. Продемонстрируйте ошибку захвата адреса переменной цикла `for range`: слайс указателей на элементы среза, все указывают на последний элемент. Исправьте, копируя переменную.

20. **Получение адреса**: Объяви переменную `x := 42`. Получи её адрес в памяти через оператор `&` и выведи его.

21. **Типы указателей**: Создайте переменные типов `int`, `string`, `bool`. Создайте для каждой из них указатель. Выведите типы этих указателей с помощью `%T`.

22. Используй встроенную функцию `new()` для создания указателя на `int` со значением 0. Измени значение через указатель.

23. Напиши функцию `Swap(a, b *int)`, которая меняет значения двух переменных через указатели. Проверь работу.

24. Реализуйте классический `swap(a, b *int)`.

25. Создай структуру `Point { X, Y int }`. Напиши функцию `MoveByValue(p Point, dx, dy int) Point` (возвращает новую точку) и `MoveByPointer(p *Point, dx, dy int)` (меняет оригинал). Сравни подходы.

26. Реализуйте функцию, принимающую `*[]int` и делающую `append`, чтобы изменение слайса (длины и ёмкости) стало видно снаружи.

27. Напишите функцию, которая принимает два указателя на числа и меняет местами значения, на которые они указывают.

28. **Разыменование**: Создайте указатель на переменную `x`. Через этот указатель измените значение `x` на `100`. Выведите `x` и проверьте, что оно изменилось.

29. Получи указатель на элемент массива (или среза) `&arr[0]`. Измени элемент через указатель.

30. Сравни два указателя на один и тот же адрес с помощью `==`.

31. **Функция new()**: Выделите память под переменную типа `int` с помощью встроенной функции `new()`. Присвойте ей значение и выведите её адрес и значение.

32. Напиши функцию `AppendToSlice(s []int, val int) []int`, которая возвращает новый слайс. Покажи, что нужно присваивать результат: `s = AppendToSlice(s, 5)`. Объясни, когда происходит реаллокация.

33. **Сравнение способов выделения**: Сравните создание указателя через `p1 := new(int)` и `var x int; p2 := &x`. Будут ли они вести себя одинаково при работе с памятью?

34. Напишите функцию, меняющую значение переменной любого типа через `interface{}` и `*` с использованием `reflect` (дополнительно).

35. Напиши функцию `IncrementByValue(x int)`, которая увеличивает `x` на 1. Вызови из `main` и покажи, что оригинальная переменная не изменилась. Объясни почему.

36. Объясните и исправьте ситуацию: в цикле `for`, переменная используется в замыкании, запускаемом позже (каверза со ссылкой).

37. **Escape-анализ (Возврат указателя)**: Напишите функцию `GetLocalPointer() *int`, которая создает локальную переменную внутри себя, присваивает ей значение и возвращает её адрес. Безопасно ли это в Go? (Изучите, почему компилятор Go переносит такую переменную в кучу — Escape Analysis, запустив сборку с флагом `go build -gcflags="-m"`).

38. **Модификация в функции**: Напишите функцию `Zeroify(val *int)`, которая устанавливает значение по указателю в `0`. Проверьте её работу на локальной переменной.

39. Напиши функцию `NilMap(m map[string]int)` и попробуй записать в неё. Что произойдёт с `nil` мапой? Объясни панику и как её избежать.

40. **Разыменование (Dereferencing)**: Имея указатель из упр. 76, получи значение по этому адресу, используя оператор `*`, и выведи его.

41. **Nil-указатель**: Создайте указатель типа `*int` без инициализации. Попробуйте вывести его значение (оно должно быть `nil`). Попробуйте разыменовать его (`*p = 5`) и зафиксируйте панику (nil pointer dereference).

42. **Попытка перетереть сам указатель**: Напишите функцию `TryToReassign(p *int)`. Внутри функции попробуйте присвоить самому указателю новый адрес `p = new(int)`. Изменится ли оригинальный указатель, который передавали извне?

43. **Массив указателей**: Создайте массив из 3 указателей на `int`. Присвойте каждому элементу адрес разных переменных. В цикле измените значения всех переменных через массив указателей.

44. **Указатели внутри структур**: Создайте структуру `Node`, у которой есть поле `Value int` и поле `Next *Node`. Соедините три такие структуры в цепочку (связный список) и обойдите его с помощью цикла `for`, выводя значения.

45. **Опциональные поля через указатели**: Создайте структуру `Profile` с полями `Name string` и `Age *int`. Напишите логику: если `Age` равен `nil`, выводить "Возраст не указан", иначе выводить реальное значение. Инициализируйте два профиля (с указанием возраста и без).

47. **Сравнение указателей**: Создай две разные переменные с одинаковым значением (например, 10). Сравни их адреса (`&a == &b`). Пойми, почему результат `false`. Затем присвой два указателя на одну и ту же переменную и убедись, что они равны.
