## Часть III-A. Условные конструкции и циклы

### 15. Условные конструкции (if / switch)

**Упражнение 3A.1.** Напиши программу, которая читает целое число из консоли и сообщает: положительное оно, отрицательное или ноль. Используй конструкцию `if / else if / else`.

**Упражнение 3A.2.** Напиши программу с **if с инициализацией**: `if x := rand.Intn(100); x > 50 { ... }`. Покажи, что переменная `x` недоступна за пределами блока `if`. Попробуй обратиться к ней ниже — получи ошибку компиляции.

**Упражнение 3A.3.** Напиши функцию `Divide(a, b float64) (float64, error)` и вызывай её через **idiomatic if**: `if result, err := Divide(x, y); err != nil { ... } else { fmt.Println(result) }`. Объясни, почему в Go принят именно такой стиль обработки ошибок.

**Упражнение 3A.4.** Напиши программу, которая определяет **високосный год**. Условие: делится на 4, но не делится на 100, либо делится на 400. Используй логические операторы `&&` и `||`.

**Упражнение 3A.5.** Напиши программу, которая по дню и месяцу рождения определяет **знак зодиака**. Используй длинную цепочку `if / else if`. Затем перепиши ту же логику через `switch` без тега (tagless switch) и сравни читаемость.

**Упражнение 3A.6.** Напиши программу с `switch` по числу: принимает `int` (1–7) и выводит название дня недели. Реализуй `default` для неверного ввода.

**Упражнение 3A.7.** Напиши программу с `switch` по **строке**: принимает команду (`"start"`, `"stop"`, `"restart"`, `"status"`) и выполняет соответствующее действие (просто выводит сообщение). Добавь `default` для неизвестной команды.

**Упражнение 3A.8.** Напиши программу с **tagless switch** (switch true): проверяет диапазон возраста и выводит категорию (`"ребёнок"`, `"подросток"`, `"взрослый"`, `"пенсионер"`). Используй сравнения в `case`.

**Упражнение 3A.9.** Напиши программу с `switch` и `fallthrough`: по номеру месяца определяет сезон. Используй `fallthrough` для группировки месяцев в сезоны (например, декабрь → зима, но fallthrough в январь? Нет, сгруппируй case'ы: `case 12, 1, 2:`). Затем сделай версию с `fallthrough`, где каждый case "проваливается" в следующий для накопления описания.

**Упражнение 3A.10.** Напиши программу с **type switch**: функция принимает `interface{}` (или `any`) и определяет тип значения (`int`, `string`, `bool`, `float64`). Для каждого типа выводит сообщение с форматированным значением. Добавь `default`.

**Упражнение 3A.11.** Напиши программу с type switch, где в каждом `case` извлекается значение с тем же именем переменной: `case int: fmt.Println(v * 2)`. Покажи, что переменная `v` в каждом case имеет тип конкретного case'а.

**Упражнение 3A.12.** Напиши программу, которая имитирует **тернарный оператор** через `if / else`. В Go нет `?:` — объясни, почему (философия языка: явность лучше краткости). Напиши функцию `Max(a, b int) int` без тернарного оператора.

**Упражнение 3A.13.** Напиши программу с **вложенными if** (3 уровня вложенности): проверка доступа к системе (активен ли пользователь, есть ли права админа, не истёк ли срок действия). Затем перепиши через **guard clauses** (ранние `return`) — сравни читаемость.

**Упражнение 3A.14.** Напиши программу с `switch` по константам `iota`. Создай перечисление `StatusPending, StatusProcessing, StatusShipped, StatusDelivered`. Функция `ProcessOrder(status int)` выводит разные сообщения в зависимости от статуса.

**Упражнение 3A.15.** Напиши программу с **сложным логическим условием**: проверка допуска на мероприятие. Условие: `(возраст >= 18 || есть_сопровождение) && есть_билет && !в_чёрном_списке`. Покажи short-circuit evaluation: создай функции-предикаты с `fmt.Println` внутри и убедись, что при `false` в левой части `&&` правая часть не вычисляется.

**Упражнение 3A.16.** Напиши программу с **guard clause** для валидации пароля: функция `ValidatePassword(p string) error` проверяет длину (≥8), наличие цифры, заглавной буквы и спецсимвола. Каждая проверка — отдельный `if` с `return fmt.Errorf(...)`. В конце `return nil`.

**Упражнение 3A.17.** Напиши программу с `switch` с **multiple cases**: `case "yes", "y", "да", "Да":` → подтверждение, `case "no", "n", "нет", "Нет":` → отказ. Покажи удобство группировки.

**Упражнение 3A.18.** Напиши программу с **switch true** для вычисления грейда (A, B, C, D, F) по проценту набранных баллов (90–100=A, 80–89=B и т.д.).

**Упражнение 3A.19.** Напиши программу, которая демонстрирует: в `switch` в Go **не происходит автоматического проваливания** (в отличие от C/C++/Java). Создай `case` без `break` и покажи, что выполняется только один case. Затем добавь `fallthrough` и покажи разницу.

**Упражнение 3A.20.** Напиши программу с вложенным `switch`: внешний — по типу операции (`"арифметика"`, `"логика"`), внутренний — по конкретной операции (`+`, `-`, `&&`, `||`). Обработай все ветки.

### 16. Циклы (for / range)

**Упражнение 3A.21.** Напиши программу с классическим `for` (C-style): `for i := 1; i <= 10; i++`. Выведи числа. Затем сделай обратный порядок (10 до 1) и с шагом 2.

**Упражнение 3A.22.** Напиши программу с `for` как **while**: `for condition { ... }`. Реализуй "угадай число": компьютер загадывает число (1–100), пользователь вводит варианты, цикл продолжается до угадывания.

**Упражнение 3A.23.** Напиши программу с **бесконечным циклом** `for { ... }` и `break` по условию. Читай ввод пользователя: если введено `"exit"` — выходи из цикла, иначе эхо-вывод строки.

**Упражнение 3A.24.** Напиши программу с `for-range` по **слайсу** `[]string`. Выведи индекс и значение каждого элемента. Затем выведи только значения, игнорируя индекс (blank identifier `_`).

**Упражнение 3A.25.** Напиши программу с `for-range` по слайсу, где тебе нужен **только индекс** (без значения). Покажи, что можно написать `for i := range slice` — это допустимый синтаксис.

**Упражнение 3A.26.** Напиши программу с `for-range` по **мапе** `map[string]int`. Выведи все ключи и значения. Запусти программу несколько раз — покажи, что **порядок итерации не гарантирован** (ключи выводятся в разном порядке).

**Упражнение 3A.27.** Напиши программу с `for-range` по **строке** `"Hello, 世界"`. Выведи индекс и руну. Объясни, почему индексы идут 0, 1, 2... 7, 10 (а не подряд) — покажи, что range итерирует по **рунам**, а индексы — байтовые смещения.

**Упражнение 3A.28.** Напиши программу, которая суммирует элементы слайса `[]int` тремя способами: классический `for i := 0; i < len(s); i++`, `for-range`, и `for` с `while`-стилем. Сравни результаты.

**Упражнение 3A.29.** Напиши программу с **вложенными циклами**: выведи таблицу умножения 10×10. Используй форматирование `fmt.Printf("%4d", i*j)` для красивых столбцов.

**Упражнение 3A.30.** Напиши программу с вложенными циклами и `break`. Покажи, что `break` прерывает только **внутренний** цикл. Найди первую пару чисел `(i, j)`, где `i*j == 21`, и выведи их.

**Упражнение 3A.31.** Напиши программу с **`break` с меткой** (label): вложенные циклы по `i` и `j`. При выполнении условия прервай **внешний** цикл из тела внутреннего. Объясни синтаксис метки.

**Упражнение 3A.32.** Напиши программу с `continue`: выведи только **нечётные** числа от 1 до 20. Затем перепиши с `continue` и меткой во вложенном цикле: пропускай итерации внутреннего цикла при определённом условии.

**Упражнение 3A.33.** Напиши программу с `for-range` по **каналу**. Создай канал `ch := make(chan int)`, запиши в него 5 чисел из горутины, закрой канал (`close(ch)`). В `main` прочитай все значения через `for v := range ch`. Объясни, почему канал нужно закрывать.

**Упражнение 3A.34.** Напиши программу с циклом `for` с **двумя переменными счётчика**: `for i, j := 0, 10; i < j; i, j = i+1, j-1`. Выводи `i` и `j` на каждой итерации. Покажи, как "сходятся" указатели.

**Упражнение 3A.35.** Напиши программу, которая реализует **do-while** через `for` (тело цикла выполняется хотя бы один раз). Запрашивай у пользователя положительное число — если ввод неверный, повторяй запрос.

**Упражнение 3A.36.** Напиши программу с `for-range` по **массиву** `[5]int` (не слайсу!). Покажи, что range копирует значение элемента в переменную цикла. Измени переменную внутри цикла — покажи, что оригинальный массив не меняется. Затем сделай то же с **слайсом** — покажи разницу.

**Упражнение 3A.37.** Напиши программу, которая ищет **первое вхождение** элемента в слайсе. Используй `for` с `break` при нахождении. Если элемент не найден — выведи сообщение после цикла (используй флаг или проверку индекса).

**Упражнение 3A.38.** Напиши программу с циклом, который **модифицирует слайс во время итерации** (добавляет элементы через `append`). Покажи каверзный случай: при реаллокации `append` может изменить базовый массив, и `range` продолжит итерировать по старому массиву. Объясни, почему это опасно.

**Упражнение 3A.39.** Напиши программу с `for-range` по мапе, внутри которого **удаляются элементы** (`delete`). Покажи, что это **безопасно** в Go (в отличие от некоторых других языков). Проверь, что все элементы обработаны корректно.

**Упражнение 3A.40.** Напиши программу, которая реализует **пагинацию** через цикл: есть список из 100 элементов, выводи их порциями по 10 штук. Используй цикл `for start := 0; start < len(items); start += 10` с срезом `items[start:end]`.

### Советы по прохождению этого блока:

1. **Сначала `if`, потом `switch`** — освой tagless switch, это очень мощная идиома Go.
2. **Обрати внимание на `range`** — это самый частый цикл в Go. Пойми разницу между итерацией по слайсу, мапе и строке.
3. **Поиграй с `fallthrough`** — пойми, когда он нужен, а когда лучше группировать `case`.
4. **Type switch** — важная конструкция для работы с `interface{}`, обязательно разберись.
5. **Guard clauses** — приучись писать `if err != nil { return }` вместо вложенных `if/else` — это go-way.
6. **Метки циклов** — редко используются, но знать полезно (особенно для `break`/`continue` во вложенных циклах).
