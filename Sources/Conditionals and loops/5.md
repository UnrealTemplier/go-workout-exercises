Отличное дополнение! В Go нет циклов `while` или `do-while`, а вся логика итераций ложится на плечи могучего `for`. Что касается условий, то `if` и `switch` в Go имеют свои очень удобные "фишки" (например, блоки инициализации), которые нужно довести до автоматизма.

Вот еще **30 интенсивных упражнений** (продолжаем нумерацию, начиная с 112), посвященных логике ветвления и циклам.

### Блок 7. Условные конструкции: if, else, switch (112–125)
Осваиваем контроль потока выполнения программы, инициализацию внутри условий и работу с `switch`.

112. **Базовый `if-else`:** Считай из консоли число. Напиши проверку: если оно четное, выведи "Четное", иначе "Нечетное" (используй оператор остатка от деления `%`).
113. **Каскадный `if`:** Считай возраст пользователя. Напиши цепочку `if - else if - else`, которая выводит: 0-12 (ребенок), 13-17 (подросток), 18-59 (взрослый), 60+ (пенсионер).
114. **`If` с инициализацией (Критически важно!):** Напиши вызов функции, которая возвращает значение и ошибку (например, `strconv.Atoi("123")`). Сделай вызов и проверку ошибки прямо в заголовке `if`: `if val, err := strconv.Atoi(...); err != nil { ... }`.
115. **Теневое копирование (Shadowing) в `if`:** Объяви `x := 10` до `if`. Затем напиши `if x := 5; x > 0 { fmt.Println(x) }`. Выведи `x` после `if`. Пойми, почему внутри `if` была 5, а снаружи осталась 10.
116. **Логические операторы:** Напиши программу, определяющую високосный ли год. Условие: год делится на 4, но НЕ делится на 100, ИЛИ делится на 400. (Используй `&&`, `||`, `!`).
117. **Базовый `switch`:** Запроси у пользователя номер дня недели (1-7) и выведи его название через `switch`. Обработай `default` случай (если введено другое число).
118. **Множественный `case`:** Перепиши упр. 117 так, чтобы на дни 1,2,3,4,5 программа выводила "Будний день", а на 6,7 — "Выходной", объединив значения через запятую в одном `case`.
119. **`Switch` без выражения (аналог каскадного if):** Перепиши упр. 113 (возрастные категории), используя конструкцию `switch { case age < 13: ... }` (без передачи переменной после слова `switch`).
120. **Провал проваливания (`fallthrough`):** В Go, в отличие от C/Java/JS, `switch` не требует `break` — он выходит автоматически. Попробуй использовать ключевое слово `fallthrough` в конце одного из `case`, чтобы заставить программу выполнить следующий `case` независимо от его условия.
121. **`Switch` с инициализацией:** По аналогии с `if`, проинициализируй переменную прямо в конструкции `switch` (`switch num := getNumber(); num { ... }`).
122. **Паттерн "Guard Clauses" (Ранний возврат):** Напиши функцию с глубокой вложенностью (`if a { if b { if c { return true } } }`). Перепиши её в "плоском" стиле, инвертируя условия и используя `return` для раннего выхода (`if !a { return false }`). Это золотой стандарт чистого кода в Go.
123. **Type switch (переключатель типов):** Напиши функцию `CheckType(v interface{})`. Внутри напиши `switch val := v.(type) { ... }`, которая проверяет, является ли `v` строкой, `int` или `bool`, и выводит соответствующее сообщение.
124. **Сложное условие с булевыми функциями:** Напиши 3 функции, возвращающие `bool` (например, проверяющие строку на длину, на наличие цифр и на наличие заглавных букв). Сделай `if`, вызывающий их через `&&`. Добавь в функции вывод логов и посмотри на эффект "короткого замыкания" (short-circuit evaluation), когда при `false` первой функции остальные даже не вызываются.
125. **`If` с мапой:** Создай `map[string]int`. Используй идиому "comma ok" прямо в `if`, чтобы проверить наличие ключа: `if val, ok := myMap["key"]; ok { ... }`.

### Блок 8. Циклы: Классические, for-range и управление потоком (126–141)
В Go только один цикл — `for`. Но его вариации перекрывают любые потребности.

126. **Классический `for`:** Напиши цикл с инициализацией, условием и шагом (`for i := 1; i <= 10; i++`). Выведи числа от 1 до 10.
127. **`For` как `while`:** Опусти блок инициализации и шага. Напиши цикл, который начинается с `n := 1` и умножает `n` на 2, пока `n < 1000`. (Вывод степеней двойки).
128. **Бесконечный цикл:** Напиши `for { ... }`. Внутри запрашивай у пользователя ввод текста. Если он ввел "exit", прерви цикл с помощью `break`.
129. **Пропуск итерации (`continue`):** Напиши цикл от 1 до 20. С помощью `if` и `continue` пропускай все нечетные числа. Выводи только четные.
130. **Вложенные циклы:** Напиши программу, которая выводит таблицу умножения (от 1 до 10) с помощью двух вложенных циклов `for`.
131. **Метки и `break` (Метка выхода):** Создай двумерный срез (матрицу чисел). Напиши два вложенных цикла для поиска числа `42`. Когда число найдено, используй метку (например, `OuterLoop:`), чтобы с помощью `break OuterLoop` выйти сразу из обоих циклов, а не только из внутреннего.
132. **Метки и `continue`:** Напиши два вложенных цикла, перебирающих `i` от 1 до 3 и `j` от 1 до 3. Если `i == j`, используй `continue OuterLoop`, чтобы мгновенно перейти к следующей итерации ВНЕШНЕГО цикла. Выведи `i` и `j` и проанализируй результат.
133. **Итерация с двумя переменными:** В классическом `for` можно делать множественные операции. Напиши цикл для разворота массива: `for i, j := 0, len(arr)-1; i < j; i, j = i+1, j-1 { ... }`.
134. **Базовый `for range` (Массивы/Срезы):** Создай срез слов. Проитерируйся по нему с помощью `for index, value := range words { ... }`. Выведи индекс и слово.
135. **Игнорирование переменных в `range`:** Вычисли сумму элементов среза чисел. Используй `range`, но проигнорируй индекс с помощью бланкового идентификатора (`for _, val := range numbers`).
136. **Каверзный случай: Изменение по значению:** Создай срез `nums := []int{1, 2, 3}`. Внутри `for _, v := range nums` попытайся умножить `v` на 10. После цикла выведи `nums`. Почему срез не изменился? (Потому что `v` — это копия значения).
137. **Правильное изменение среза в `range`:** Перепиши упр. 136. Оставь только индекс `for i := range nums` (или `for i, _ :=`) и изменяй оригинальный элемент: `nums[i] *= 10`.
138. **`Range` по мапе:** Создай `map[string]string` со столицами стран. Перебери мапу через `range`. Запусти программу 5 раз подряд и обрати внимание, что **порядок вывода элементов меняется** (Go намеренно рандомизирует обход map для защиты от завязки на порядок).
139. **`Range` по строке (байты vs руны):** Объяви строку `str := "Привет, Go!"`. Перебери её через классический цикл `for i := 0; i < len(str); i++` и выведи символы (через `string(str[i])`). Затем перебери её через `for index, char := range str`. Сравни вывод. Пойми, почему первый вариант ломает кириллицу, а `range` корректно читает руны, перескакивая через индексы (0, 2, 4...).
140. **Изменение мапы во время итерации:** Создай мапу и начни её обход через `range`. Внутри цикла добавляй в эту же мапу новые ключи. Узнай из документации, будут ли пройдены новые ключи в текущем цикле (спойлер: поведение не детерминировано).
141. **Пустой `range`:** Инициализируй пустой срез (`var s []int` или `s := []int{}`). Запусти по нему `range`. Убедись, что программа не падает с паникой (как могло бы быть в других языках с null), цикл просто ни разу не выполнится.
