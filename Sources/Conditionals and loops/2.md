### 3. Условные конструкции и циклы (добавленный раздел)

21. **Простое условие**: запросите у пользователя целое число и выведите `Even` / `Odd` через `if-else`.
22. **`if` с коротким объявлением**: внутри условия объявите переменную `age := ...` и используйте её только в блоках `if/else if/else`.
23. **Цепочка `if-else if-else`**: переведите числовую оценку (0–100) в буквенную (A, B, C, D, F) с несколькими ветками.
24. **Классический `switch`**: напишите `switch` для дня недели (1–7) и выведите название дня.
25. **`switch` без выражения**: превратите предыдущий пример в `switch { case day == 1: ... }` (true switch).
26. **Несколько значений в `case`**: определите выходной или будний день через `case 6, 7:`.
27. **`fallthrough`**: продемонстрируйте, как `fallthrough` передаёт управление следующему `case`, и объясните, зачем это нужно.
28. **`type switch`**: создайте несколько переменных разных типов, присвойте их `interface{}` и внутри `switch v := x.(type)` выведите название типа.
29. **Цикл `for` с тремя компонентами**: выведите все чётные числа от 1 до 20, используя `i += 2`.
30. **`for` без постусловия** (как `while`): запрашивайте у пользователя пароль до тех пор, пока он не введёт `"secret"`.
31. **Бесконечный цикл с явным выходом**: `for { ... break }` – читайте ввод и выводите удвоенную строку, пока не будет введено `"exit"`.
32. **`for range` по срезу**: просуммируйте все элементы `[]int{10, 20, 30, 40}` и выведите сумму.
33. **`for range` по `map`**: пройдите по `map[string]int{"a":1, "b":2}` и выведите ключ-значение.
34. **`for range` по строке**: подсчитайте количество букв, цифр и пробелов в строке, используя `for _, r := range s`.
35. **`break` и `continue`**: в цикле от 1 до 10 пропускайте (`continue`) нечётные числа и останавливайтесь (`break`), если встретили число 8.
36. **Вложенные циклы**: выведите таблицу умножения 10×10 с аккуратным форматированием через `fmt.Printf`.
37. **Метка и `break`**: во вложенном цикле поиска простых чисел от 2 до 50 используйте метку `outer` для выхода из внешнего цикла при нахождении составного числа.
38. **`goto`**: напишите алгоритм поиска первого отрицательного числа в срезе с использованием `goto` (аккуратно и осмысленно).
39. **FizzBuzz**: от 1 до 30: если число делится на 3 — `Fizz`, на 5 — `Buzz`, на оба — `FizzBuzz`, иначе само число.
40. **Проверка високосного года**: запросите год и выведите результат, используя `if-else` и логические операторы.
41. **`switch` с `bool`-выражениями**: реализуйте калькулятор: спросите два числа и операцию (`+`, `-`, `*`, `/`), затем через `switch operation` выполните вычисление.
42. **Каверза `for range`**: создайте срез структур `[]Person`, пройдите по нему с `for _, p := range`, попробуйте изменить поле у `p` и объясните, почему оригинальный срез не изменился.
43. **Инициализация в `if` и область видимости**: `if x := getValue(); x > 0 { ... } else { // здесь x тоже видна }`, покажите ограниченную область `x`.
44. **Меню с бесконечным циклом и `switch`**: программа постоянно показывает пункты меню, выполняет действие по вводу и выходит по `"quit"`.
45. **Поиск подстроки с циклом и флагом**: проверьте, содержится ли слово "Go" в заранее заданном срезе строк, используя булев флаг и `break` для оптимизации.
