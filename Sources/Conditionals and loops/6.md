### Раздел 8: Условные конструкции (Задачи 116–127)

*В этом блоке вы проработаете ветвление логики, научитесь ограничивать область видимости переменных внутри условий и освоите различные формы оператора `switch`.*

116. **Базовый `if-else`**: Напишите программу, которая запрашивает у пользователя целое число и выводит в консоль, является ли оно четным или нечетным.
117. **Множественные ветвления**: Напишите программу, определяющую оценку студента по 100-балльной шкале: 90+ — "A", 80-89 — "B", 70-79 — "C", 50-69 — "D", меньше 50 — "F". Используйте цепочку `if - else if - else`.
118. **Инициализация внутри `if`**: Напишите условную конструкцию с краткой инициализацией переменной: `if x := getSomeValue(); x > limit { ... }`. Попробуйте обратиться к переменной `x` вне этого блока `if-else`. Зафиксируйте ошибку компиляции и сделайте вывод о границах видимости (scope) такой переменной.
119. **Булевы упрощения**: Создайте переменную `isValid bool = true`. Напишите условие `if`, проверяющее её значение. Избегайте явного сравнения вида `if isValid == true` — напишите идиоматичный для Go вариант.
120. **Базовый `switch` по значению**: Напишите программу, которая принимает число от 1 до 7 (день недели) и с помощью конструкции `switch` выводит название этого дня (например, 1 — "Понедельник"). Добавьте ветку `default` для обработки некорректных чисел.
121. **Множественные значения в `case`**: Перепишите предыдущую программу с днями недели так, чтобы `switch` группировал дни: в одном `case` перечислялись будни (1, 2, 3, 4, 5) и выводилось "Будний день", а в другом — выходные (6, 7) с выводом "Выходной".
122. **`switch` без выражения (Tagless switch)**: Напишите аналог цепочки `if-else` из задачи №117 (определение оценки по баллам), используя `switch` без указания переменной после ключевого слова (когда условия пишутся прямо в ветках `case`, например, `case score >= 90:`).
123. **Эффект `fallthrough`**: Создайте `switch` по целому числу от 1 до 3. В ветках `case 1` и `case 2` добавьте ключевое слово `fallthrough`. Запустите программу, передав на вход `1`, и проанализируйте, почему выполнился код всех последующих веток.
124. **Принудительный выход из `switch`**: Напишите `switch`, проверяющий тип операции (например, строка `"sum"`). Внутри одной из веток `case` добавьте условие: если дополнительный параметр равен нулю, прервать выполнение этой ветки досрочно с помощью `break`, не выполняя оставшуюся часть кода в этом `case`.
125. **Инициализация внутри `switch`**: Объявите и инициализируйте переменную прямо в строке объявления `switch` (например, `switch age := getAge(); { case age < 18: ... }`). Убедитесь, что переменная `age` недоступна за пределами блока `switch`.
126. **Проверка типов (Type switch)**: Создайте переменную типа `any` (или `interface{}`). Присвойте ей сначала число, затем строку. Напишите конструкцию `switch v := x.(type)`, которая определяет динамический тип переменной и выводит соответствующее сообщение (например, "Это целое число", "Это строка").
127. **Логическое сокращение (Short-circuit)**: Напишите функцию `isTrue() bool`, которая выводит в консоль "Вызвана isTrue" и возвращает `true`, и аналогичную функцию `isFalse() bool`, возвращающую `false`. Напишите условие `if isFalse() && isTrue()`. Посмотрите на вывод в консоли и объясните, почему функция `isTrue` даже не была вызвана (эффект короткого замыкания логических операторов).

### Раздел 9: Циклы (for, for-range) и управление ими (Задачи 128–140)

*В этом блоке вы изучите единственный цикл в Go — `for` — во всех его проявлениях, научитесь работать с коллекциями и управлять вложенными циклами с помощью меток.*

128. **Классический цикл**: Напишите стандартный трехкомпонентный цикл `for` (инициализация; условие; шаг) для вывода чисел от 1 до 10.
129. **Обратный отсчет**: Напишите трехкомпонентный цикл `for`, который выводит числа от 10 до 1 в обратном порядке, а в конце выводит слово `"Старт!"`.
130. **Аналог цикла `while`**: В Go нет ключевого слова `while`. Напишите цикл `for`, содержащий только условие (например, `for x < 100`). Пусть внутри цикла переменная `x` умножается на 2 на каждой итерации.
131. **Бесконечный цикл и `break`**: Напишите бесконечный цикл `for { ... }`. Внутри цикла считывайте числа из консоли. Если пользователь вводит число `0`, прервите цикл с помощью инструкции `break`.
132. **Пропуск итерации с `continue`**: Напишите цикл от 1 до 20. С помощью оператора `continue` сделайте так, чтобы программа выводила в консоль только нечетные числа.
133. **Итерация по срезу через `for range`**: Создайте срез строк `[]string{"яблоко", "банан", "груша"}`. Используя цикл `for index, value := range slice`, выведите индекс и значение каждого элемента.
134. **Игнорирование параметров в `range`**: Используя тот же срез фруктов, напишите два цикла: первый должен выводить только индексы элементов, а второй — только сами значения (используя пустой идентификатор `_` для пропуска индекса).
135. **Итерация по строке (байты vs руны)**: Создайте строку `"Привет"`.
    * Напишите обычный цикл `for i := 0; i < len(str); i++` и выведите `str[i]`. Обратите внимание на странные символы в выводе (так как считываются отдельные байты UTF-8).
    * Напишите цикл `for index, runeValue := range str` и выведите индекс и символ. Объясните, почему индексы идут не по порядку (0, 2, 4...) и как `for range` автоматически декодирует символы UTF-8 (руны).
136. **Итерация по отображению (Map)**: Создайте мапу `map[string]int` с именами и возрастами. Запустите цикл `for key, val := range myMap` для вывода содержимого. Запустите программу 5 раз подряд. Обратите внимание, меняется ли порядок вывода элементов при каждом запуске (изучите non-deterministic поведение итерации по мапам в Go).
137. **Вложенные циклы**: Напишите программу, которая выводит в консоль таблицу умножения от 1 до 10 в виде аккуратной сетки.
138. **Выход из вложенного цикла (Метки/Labels)**: Создайте два вложенных цикла (внешний по `i` от 1 до 5, внутренний по `j` от 1 до 5). Напишите условие: если `i == 3` и `j == 3`, нужно полностью прервать оба цикла. Используйте для этого именованную метку (label) перед внешним циклом и команду `break ИМЯ_МЕТКИ`.
139. **Переход к следующей итерации внешнего цикла**: Используя те же вложенные циклы, сделайте так, чтобы при достижении условия `j == 3` программа прекращала выполнение текущей итерации внутреннего цикла и сразу переходила к следующему шагу *внешнего* цикла. Используйте `continue ИМЯ_МЕТКИ`.
140. **Каверзный случай: Копирование значений в `for range`**: 
    * Создайте срез структур `[]Product{{Name: "A", Price: 10}, {Name: "B", Price: 20}}`.
    * Напишите цикл `for _, prod := range products { prod.Price = 100 }`.
    * Выведите исходный срез после цикла. Изменились ли цены продуктов?
    * Напишите правильный вариант изменения элементов среза в цикле (через обращение по индексу: `products[i].Price = 100`) и объясните, почему первый вариант не сработал (подсказка: переменная цикла `prod` получает лишь копию элемента на каждой итерации).
