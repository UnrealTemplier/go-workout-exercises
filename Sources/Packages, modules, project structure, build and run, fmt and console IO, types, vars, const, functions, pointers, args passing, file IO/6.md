### Раздел 1: Модули, пакеты, компиляция и запуск (Задачи 1–15)

*Этот блок поможет вам освоить инфраструктуру Go, научиться управлять проектами, компилировать код под разные платформы и организовывать структуру файлов.*

1. **Инициализация модуля**: Создайте пустую директорию `hello_mod`. Инициализируйте в ней Go-модуль с помощью команды `go mod init hello_mod`. Убедитесь, что файл `go.mod` успешно создался, и изучите его содержимое.
2. **Первый запуск**: Создайте файл `main.go` в корне вашего модуля. Напишите базовую функцию `main`, которая выводит строку `"Hello, Go!"`. Запустите программу напрямую без компиляции с помощью команды `go run main.go`.
3. **Компиляция исполняемого файла**: Скомпилируйте ваш проект `hello_mod` с помощью команды `go build`. Найдите появившийся исполняемый файл (бинарник) в директории и запустите его из консоли напрямую (например, `./hello_mod` или `hello_mod.exe`).
4. **Установка в систему**: Используйте команду `go install`. Найдите, куда Go сохранил скомпилированный бинарный файл (проверьте директорию `$GOPATH/bin` или `$HOME/go/bin`). Попробуйте вызвать программу из консоли из любой другой директории.
5. **Кросс-компиляция**: Находясь на своей текущей операционной системе, скомпилируйте исполняемый файл для другой ОС (например, если вы на Windows, скомпилируйте для Linux с помощью команды `GOOS=linux GOARCH=amd64 go build`, или наоборот). Убедитесь, что создался файл другого формата.
6. **Создание подпакета**: Внутри модуля создайте новую папку `calculator`. Внутри нее создайте файл `calc.go` с пакетом `package calculator`. Напишите там простую экспортируемую функцию `Add(a, b int) int`. Импортируйте этот пакет в свой `main.go` и вызовите функцию.
7. **Разделение одного пакета**: Создайте файл `helper.go` в той же директории, где находится `main.go` (оба файла должны объявлять `package main`). Перенесите часть логики вывода в `helper.go`. Запустите проект с помощью `go run main.go helper.go` или `go run .`.
8. **Экспорт и видимость**: В пакете `calculator` создайте две функции: одну с заглавной буквы (`Sub`), другую со строчной (`multiply`). Попробуйте вызвать обе из пакета `main`. Зафиксируйте ошибку компиляции для неэкспортируемой функции.
9. **Функция инициализации пакета**: Напишите функцию `init()` в пакете `calculator`, которая выводит текст `"Calculator init"`. Напишите аналогичную функцию `init()` в пакете `main`. Запустите программу и посмотрите на порядок вывода сообщений.
10. **Несколько init-функций**: Напишите две разные функции `init()` в одном файле `main.go`. Напишите еще одну в файле `helper.go` (тоже `package main`). Посмотрите, выполняются ли они все и в каком порядке.
11. **Подключение внешней зависимости**: Инициализируйте новый модуль. Найдите на GitHub или pkg.go.dev популярную библиотеку (например, `github.com/google/uuid`). Скачайте её с помощью `go get github.com/google/uuid`. Убедитесь, что в `go.mod` появилась запись, а также создался файл `go.sum`.
12. **Использование стороннего пакета**: Внедрите импорт `github.com/google/uuid` в ваш код. Сгенерируйте UUID версии 4 и выведите его в консоль.
13. **Очистка зависимостей**: Удалите из кода `main.go` использование библиотеки `uuid`, но оставьте её в импортах. Выполните команду `go mod tidy`. Посмотрите, как изменились файлы `go.mod` и `go.sum`.
14. **Псевдонимы (алиасы) пакетов**: Импортируйте ваш пакет `calculator` под другим именем (например, `calc`). Используйте новый алиас для вызова функций пакета: `calc.Add(...)`.
15. **Импорт ради побочных эффектов**: Импортируйте пакет `calculator` с использованием пустого идентификатора `_ "hello_mod/calculator"`. Убедитесь, что функция `init()` из него вызывается, даже если вы не используете функции пакета напрямую.

### Раздел 2: Консольный ввод/вывод и пакет `fmt` (Задачи 16–30)

*Здесь вы детально разберете форматирование строк, работу со стандартными потоками ввода/вывода (Stdout, Stdin, Stderr) и буферизацией.*

16. **Базовый вывод**: Напишите программу, которая выводит три строки с помощью `fmt.Println` и три строки с помощью `fmt.Print`. Обратите внимание на автоматическую расстановку пробелов и переносов строк.
17. **Универсальный спецификатор**: Создайте переменные разных типов (число, строка, булево). Выведите их в консоль, используя `fmt.Printf` со спецификатором `%v`.
18. **Подробный вывод структур**: Создайте простую структуру `User` с полями `Name` и `Age`. Инициализируйте её. Выведите её в консоль тремя способами: через `%v`, `%+v` и `%#v`. Сравните результаты.
19. **Вывод типов**: Напишите программу, которая принимает переменные разных типов и выводит их тип в консоль с помощью спецификатора `%T`.
20. **Форматирование чисел**: Выведите одно и то же целое число в десятичном (`%d`), двоичном (`%b`), восьмеричном (`%o`) и шестнадцатеричном (`%x` и `%X`) форматах.
21. **Форматирование вещественных чисел**: Выведите число типа `float64` (например, число Пи) с точностью до 2, 4 и 10 знаков после запятой.
22. **Экранирование строк**: Выведите строковую переменную, содержащую кавычки и переносы строк, с помощью `%q`. Посмотрите, как Go экранирует эти спецсимволы.
23. **Форматирование без вывода**: Используйте функцию `fmt.Sprintf` для сборки строки из различных переменных. Сохраните результат в переменную и выведите её позже через `println`.
24. **Базовый ввод слов**: Напишите программу, которая запрашивает у пользователя имя (одно слово) через `fmt.Scan` и здоровается с ним.
25. **Ввод нескольких значений**: Запросите у пользователя имя и возраст в одну строку, разделенные пробелом, используя `fmt.Scanln`. Сохраните их в соответствующие переменные.
26. **Шаблонный ввод**: Напишите программу, которая считывает дату в формате `ДД/ММ/ГГГГ` с помощью функции `fmt.Scanf` и раскладывает её на три целочисленные переменные (день, месяц, год).
27. **Чтение строки с пробелами**: Попробуйте ввести ФИО с пробелами через `fmt.Scan`. Обратите внимание, почему считывается только первое слово. Исправьте это, применив `bufio.NewReader(os.Stdin)` и метод `ReadString('\n')`.
28. **Чтение до определенного символа**: Напишите программу, которая считывает текст из консоли до тех пор, пока пользователь не введет точку `.`. Используйте `bufio`.
29. **Вывод ошибок в Stderr**: Напишите функцию, которая имитирует ошибку. Выведите сообщение об ошибке в поток стандартной ошибки `os.Stderr` с помощью `fmt.Fprintln`.
30. **Полноценная CLI-анкета**: Создайте утилиту, которая запрашивает имя, возраст и email. Если возраст отрицательный или равен нулю, программа должна вывести ошибку в `os.Stderr` и завершиться с кодом `os.Exit(1)`. Если всё верно, вывести красивую карточку пользователя в `os.Stdout`.

### Раздел 3: Переменные, константы и базовые типы (Задачи 31–50)

*Этот блок сфокусирован на системе типов Go, правилах видимости переменных, затенении, константах и работе с перечислениями.*

32. **Краткое объявление**: Создайте несколько переменных с помощью оператора `:=`. Попробуйте изменить их тип после объявления (например, присвоить строке число). Зафиксируйте поведение компилятора.
33. **Мульти-объявление**: Объявите три переменные разных типов в одной строке (например, `a, b, c := 1, 2.5, "hello"`). Выведите их значения.
34. **Блочное объявление**: Объявите группу переменных разных типов, используя ключевое слово `var` и круглые скобки `var (...)`.
35. **Глобальные vs Локальные**: Объявите переменную на уровне пакета (вне функций). Объявите переменную с таким же именем внутри функции `main`. Выведите значение внутри функции. Какая переменная приоритетнее? Попробуйте использовать оператор `:=` на уровне пакета и объясните ошибку компиляции.
36. **Затенение в блоках (Shadowing)**: Напишите блок `if true { ... }`. Внутри блока объявите переменную с именем, которое уже используется во внешней функции. Измените её значение внутри блока. Выведите значение переменной до блока, внутри блока и после блока.
37. **Приведение типов**: Создайте переменную `int32` и `float64`. Попробуйте сложить их напрямую. Исправьте ошибку компиляции с помощью явного приведения типов.
38. **Переполнение типов (Overflow)**: Объявите переменную типа `uint8` со значением `255`. Прибавьте к ней `1`. Выведите результат. Объясните поведение.
39. **Работа с рунами**: Объявите переменную типа `rune` со значением `'Ш'`. Выведите её числовое представление (код Unicode), а затем преобразуйте в строку и выведите как символ.
40. **Преобразование строк в байты**: Создайте строку `"Go язык"`. Преобразуйте её в срез байт `[]byte`. Выведите длину полученного среза. Почему длина среза байт больше, чем количество символов в строке?
41. **Простые константы**: Объявите типизированную константу `const Limit int = 100` и нетипизированную константу `const Speed = 300000`. Попробуйте изменить значение константы в коде.
42. **Групповые константы**: Объявите блок констант, описывающих математические величины (Пи, Экспонента) через `const (...)`.
43. **Нетипизированные константы в действии**: Создайте нетипизированную константу `const X = 5`. Объявите переменные типов `int`, `float64`, `complex128`. Попробуйте умножить каждую из переменных на `X` без явного приведения типов.

46. **Пропуск значений в iota**: Создайте перечисление, в котором значения 0 и 1 пропускаются с помощью пустого идентификатора `_`, а константы начинаются со значения 2.

48. **Сравнение вещественных чисел**: Создайте две переменные `float64` со значениями `0.1 + 0.2` и `0.3`. Сравните их через `==`. Напишите правильную функцию сравнения вещественных чисел с использованием небольшой дельты (эпсилон).

### Раздел 4: Функции: все грани и вариации (Задачи 51–70)

*Функции в Go — объекты первого класса. В этом блоке вы изучите все способы их объявления, замыкания, отложенные вызовы (defer) и обработку паник.*

51. **Простая функция**: Напишите функцию `SayHello()`, которая просто печатает приветствие в консоль.
52. **Параметры и возврат**: Напишите функцию `Square(n int) int`, возвращающую квадрат числа.
53. **Сокращенный синтаксис параметров**: Напишите функцию `SumThree(a, b, c int) int`, демонстрирующую группировку однотипных аргументов.
54. **Множественный возврат**: Напишите функцию `Divide(a, b float64) (float64, error)`, которая возвращает результат деления и ошибку, если делитель равен нулю.
55. **Именованный возврат**: Напишите функцию `RectangleStats(width, height float64) (area, perimeter float64)`, которая вычисляет площадь и периметр прямоугольника, используя именованные возвращаемые значения.
56. **"Голый" возврат (Naked return)**: Перепишите предыдущую функцию `RectangleStats` так, чтобы она использовала "голый" оператор `return`. Напишите комментарий, почему в больших функциях этого стоит избегать.
57. **Вариативные параметры**: Напишите функцию `Concat(sep string, words ...string) string`, которая соединяет переданные строки через разделитель.
58. **Распаковка среза**: Создайте срез строк `[]string{"Go", "is", "awesome"}`. Передайте его в созданную ранее функцию `Concat` с использованием оператора `...`.
59. **Анонимная функция (IIFE)**: Напишите и сразу же вызовите анонимную функцию, которая выводит текущее время.
60. **Функция как переменная**: Создайте переменную `operation` типа "функция, принимающая два `int` и возвращающая `int`". Присвойте ей анонимную функцию сложения, а затем замените её на функцию умножения.
61. **Функция как аргумент (Callback)**: Напишите функцию `Filter(numbers []int, predicate func(int) bool) []int`. Передайте в неё срез чисел и функцию, проверяющую числа на четность.
62. **Функция как возвращаемое значение**: Напишите функцию `CreateMultiplier(factor int) func(int) int`, которая возвращает функцию, умножающую переданное число на `factor`.
63. **Замыкание (Closure)**: Создайте генератор идентификаторов `NewIDGenerator() func() int`. Каждый вызов возвращенной функции должен возвращать число на 1 больше предыдущего (начиная с 1).
64. **Замыкание в цикле (Исторический баг)**: Создайте срез функций `funcs := make([]func(), 3)`. В цикле `for i := 0; i < 3; i++` заполните этот срез анонимными функциями, каждая из которых выводит `i`. Запустите эти функции после цикла. Какое поведение вы увидите? (Учтите особенности версий Go до 1.22 и современных).
65. **Базовый defer**: Напишите функцию, которая открывает гипотетический ресурс (выводит "ресурс открыт"), затем производит вычисления, а закрытие ресурса ("ресурс закрыт") гарантирует с помощью `defer`.
66. **Порядок выполнения defer (LIFO)**: Напишите функцию, в которой друг за другом вызываются три оператора `defer` с выводом чисел 1, 2 и 3. Убедитесь в порядке их выполнения (стек).
67. **Изменение именованного возврата в defer**: Напишите функцию `DoubleValue(x int) (result int)`. В теле функции присвойте `result = x`. Внутри `defer` удвойте значение `result`. Проверьте, какое значение вернет функция при вызове.
68. **Замер времени выполнения**: Напишите функцию `SlowWorker()`, которая засыпает на 100 миллисекунд (`time.Sleep`). С помощью связки `defer` и функции `time.Now()` / `time.Since()` сделайте автоматический замер и вывод времени её работы при завершении.
69. **Panic и Recover**: Напишите функцию, которая провоцирует панику (`panic("критическая ошибка")`). Оберните вызов в функцию с `recover()` внутри `defer`, чтобы программа не завершалась аварийно, а корректно обрабатывала инцидент.
70. **Рекурсия**: Напишите рекурсивную функцию для нахождения n-го числа Фибоначчи.

### Раздел 5: Указатели: основы и операции (Задачи 71–85)

*Этот раздел поможет вам понять, как Go работает с памятью, адресами переменных и ссылочной моделью.*

71. **Получение адреса**: Создайте переменную `x = 42`. Получите её адрес в памяти с помощью `&` и выведите его в консоль в шестнадцатеричном формате.
72. **Разыменование**: Создайте указатель на переменную `x`. Через этот указатель измените значение `x` на `100`. Выведите `x` и проверьте, что оно изменилось.
73. **Типы указателей**: Создайте переменные типов `int`, `string`, `bool`. Создайте для каждой из них указатель. Выведите типы этих указателей с помощью `%T`.
74. **Nil-указатель**: Создайте указатель типа `*int` без инициализации. Попробуйте вывести его значение (оно должно быть `nil`). Попробуйте разыменовать его (`*p = 5`) и зафиксируйте панику (nil pointer dereference).
75. **Функция new()**: Выделите память под переменную типа `int` с помощью встроенной функции `new()`. Присвойте ей значение и выведите её адрес и значение.
76. **Сравнение способов выделения**: Сравните создание указателя через `p1 := new(int)` и `var x int; p2 := &x`. Будут ли они вести себя одинаково при работе с памятью?
77. **Сравнение указателей**: Создайте две разные переменные с одинаковым значением `42`. Получите их указатели. Сравните эти указатели (`p1 == p2`). Создайте два указателя на одну и ту же переменную и сравните их.
78. **Указатель на указатель**: Создайте переменную `x = 10`. Создайте указатель `p` на `x`, и указатель `pp` на `p` (`**int`). Измените значение `x` через `pp`.
79. **Модификация в функции**: Напишите функцию `Zeroify(val *int)`, которая устанавливает значение по указателю в `0`. Проверьте её работу на локальной переменной.
80. **Попытка перетереть сам указатель**: Напишите функцию `TryToReassign(p *int)`. Внутри функции попробуйте присвоить самому указателю новый адрес `p = new(int)`. Изменится ли оригинальный указатель, который передавали извне?
81. **Escape-анализ (Возврат указателя)**: Напишите функцию `GetLocalPointer() *int`, которая создает локальную переменную внутри себя, присваивает ей значение и возвращает её адрес. Безопасно ли это в Go? (Изучите, почему компилятор Go переносит такую переменную в кучу — Escape Analysis, запустив сборку с флагом `go build -gcflags="-m"`).
82. **Указатели на структуры**: Создайте структуру `Employee` с полем `Salary`. Напишите функцию `GiveBonus(e *Employee, amount int)`, которая увеличивает зарплату. Передайте структуру по указателю.
83. **Массив указателей**: Создайте массив из 3 указателей на `int`. Присвойте каждому элементу адрес разных переменных. В цикле измените значения всех переменных через массив указателей.
84. **Указатели внутри структур**: Создайте структуру `Node`, у которой есть поле `Value int` и поле `Next *Node`. Соедините три такие структуры в цепочку (связный список) и обойдите его с помощью цикла `for`, выводя значения.
85. **Опциональные поля через указатели**: Создайте структуру `Profile` с полями `Name string` и `Age *int`. Напишите логику: если `Age` равен `nil`, выводить "Возраст не указан", иначе выводить реальное значение. Инициализируйте два профиля (с указанием возраста и без).

### Раздел 6: Передача аргументов: по значению vs по ссылке, каверзные случаи (Задачи 86–100)

*Один из самых важных разделов. Вы детально разберете, как Go копирует данные при передаче в функции, и почему "ссылочные" типы данных ведут себя по-особенному.*

86. **Передача int по значению**: Напишите функцию `ModifyValue(x int)`. Внутри измените `x`. Докажите выводом адресов внутри и снаружи функции, что внутри работает копия переменной.
87. **Передача int по ссылке**: Перепишите функцию `ModifyValue`, чтобы она принимала `*int`. Сравните адреса переменной снаружи и указателя внутри функции.
88. **Копирование структур**: Создайте структуру большого размера (например, с 10 полями). Напишите функцию, принимающую её по значению, и функцию, принимающую её по указателю. Выведите адреса структуры в обоих случаях.
89. **Срезы (Slices): Модификация элементов**: Передайте срез `[]int{1, 2, 3}` в функцию по значению. Внутри функции измените первый элемент: `slice[0] = 99`. Изменился ли исходный срез вне функции? Объясните почему (подсказка: структура среза содержит указатель на базовый массив).
90. **Срезы: Каверзный случай с append**: Передайте срез в функцию по значению. Внутри функции сделайте `append(slice, 4)`. Выведите срез внутри функции и снаружи. Почему новый элемент не появился в исходном срезе снаружи?
91. **Передача среза по указателю**: Напишите функцию `AppendWithPointer(slice *[]int, val int)`. Передайте туда срез по указателю и примените `append`. Убедитесь, что теперь изменения (размер и емкость) отразились снаружи.
92. **Отображения (Maps): Передача по значению**: Передайте мапу `map[string]int` в функцию по значению. Внутри функции добавьте новый ключ или измените существующий. Изменилась ли мапа снаружи? (Изучите, почему мапа в Go является указателем на структуру `hmap` под капотом).
93. **Мапы: Попытка обнуления**: Передайте мапу в функцию по значению. Внутри функции присвойте ей `nil` или создайте новую мапу через `make`. Изменится ли исходная мапа снаружи?
94. **Каналы (Channels) как ссылочный тип**: Создайте канал. Передайте его в функцию по значению. Запишите данные в канал внутри функции, а прочитайте снаружи. Работает ли передача каналов по значению как передача ссылки?
95. **Массивы (Arrays) фиксированной длины**: Создайте массив `[5]int{1, 2, 3, 4, 5}`. Передайте его в функцию по значению. Измените элемент внутри функции. Изменился ли массив снаружи? (Обратите внимание на ключевое отличие поведения массивов от срезов в Go).
96. **Массивы по указателю**: Напишите функцию, принимающую указатель на массив `*[5]int`. Измените элементы и убедитесь, что изменения сохранились.
97. **Структура со срезом внутри**: Создайте структуру `Group`, содержащую поле `Members []string`. Передайте экземпляр `Group` в функцию по значению. Измените элемент среза `Members[0] = "New"`. Изменился ли этот элемент в исходной структуре снаружи?
98. **Структура с указателем (Утечка состояния)**: Создайте структуру `Config` с полем `Timeout *time.Duration`. Создайте экземпляр, скопируйте его в другую переменную простым присваиванием `cfg2 := cfg1`. Измените `Timeout` в `cfg2`. Что произошло с `Timeout` в `cfg1`? Как это предотвратить (глубокое копирование)?
99. **Ознакомление с пакетом unsafe**: Используя пакет `unsafe` и `unsafe.Pointer`, получите указатель на первое поле структуры и, прибавив к адресу смещение, получите доступ ко второму полю без использования его имени. *(Внимание: используйте это только в учебных целях).*
100. **Поведение кастомных типов**: Создайте тип-алиас `type MyInt int`. Напишите методы или функции, принимающие `MyInt` по значению и по ссылке. Убедитесь, что правила передачи не меняются.

### Раздел 7: Работа с файлами: чтение, запись, бинарный и текстовый ввод/вывод (Задачи 101–115)

*Этот блок посвящен работе с операционной системой и диском. Вы научитесь читать и записывать текстовые файлы, работать с буферизацией, обрабатывать бинарные данные и безопасно закрывать дескрипторы.*

101. **Создание файла**: Напишите программу, которая создает новый пустой файл `test.txt` с помощью `os.Create`. Обязательно обеспечьте закрытие файла через `defer file.Close()`.
102. **Проверка существования**: Напишите функцию, которая проверяет, существует ли файл по заданному пути, используя `os.Stat` и `os.IsNotExist`.
103. **Открытие для чтения**: Напишите код, который открывает существующий файл `test.txt` в режиме "только для чтения" с помощью `os.Open`. Обработайте возможную ошибку (например, если файла нет).
104. **Запись строки**: Откройте файл на запись и запишите в него строку `"Привет, Go!"` с помощью метода `file.WriteString`.
105. **Запись среза байт**: Запишите в файл массив байт (например, `[]byte{65, 66, 67, 10}`) с помощью метода `file.Write`. Проверьте, какие символы появились в файле.
106. **Быстрое чтение всего файла**: Используя функцию `os.ReadFile`, прочитайте весь файл `test.txt` за один вызов. Преобразуйте результат в строку и выведите его в консоль.
107. **Быстрая запись всего файла**: Используя функцию `os.WriteFile`, запишите массив байт в новый файл `fast.txt`, указав права доступа `0644`.
108. **Построчное чтение (Scanner)**: Создайте большой текстовый файл с несколькими строками текста. Напишите программу, которая с помощью `bufio.NewScanner` считывает этот файл построчно и выводит каждую строку с префиксом `[Line X]: `.
109. **Посимвольное или пословное чтение**: Используя `bufio.Scanner` и метод `scanner.Split(bufio.ScanWords)`, настройте сканер так, чтобы он читал файл не построчно, а слово за словом. Выведите каждое слово на новой строке.
110. **Буферизованная запись (Writer)**: Напишите программу, которая записывает 10 000 строк в файл. Используйте `bufio.NewWriter`. Не забудьте вызвать метод `Flush()` в конце (объясните в комментариях, почему без `Flush` часть данных может не записаться).
111. **Дозапись в файл (Append)**: Откройте существующий файл с помощью `os.OpenFile` с флагами `os.O_APPEND|os.O_WRONLY`. Допишите новую строку в конец файла, не стирая старое содержимое.
112. **Произвольное позиционирование (Seek)**: Откройте файл. Используйте метод `file.Seek`, чтобы переместить указатель чтения/записи на 5 байт вперед от начала файла. Прочитайте следующие 3 байта и выведите их.
113. **Бинарная запись**: Создайте структуру `PlayerData` с полями `ID uint32`, `Level uint16`, `Score float32`. Используя пакет `encoding/binary`, запишите эту структуру в файл `player.dat` в бинарном формате (в кодировке Little Endian).
114. **Бинарное чтение**: Откройте файл `player.dat`. Считайте из него бинарные данные напрямую в новую структуру `PlayerData` с помощью `binary.Read`. Выведите поля структуры, чтобы убедиться в правильности восстановления.
115. **Временные файлы**: Напишите программу, которая создает временный файл с помощью `os.CreateTemp`, записывает туда конфиг, читает его, а перед самым выходом из программы удаляет этот файл с диска с помощью `os.Remove`.

### Советы по прохождению этого курса упражнений:

1. **Пишите код руками**. Не копируйте шаблоны, старайтесь набирать каждую строчку самостоятельно, чтобы наработать мышечную память синтаксиса Go.
2. **Обращайте внимание на ошибки компилятора**. Язык Go очень строг к неиспользуемым переменным или импортам, неявным приведениям типов. Эти ограничения созданы, чтобы помогать вам писать надежный код.
3. **Используйте встроенный инструмент форматирования**. Перед запуском кода всегда выполняйте команду `go fmt имя_файла.go` — это стандарт оформления кода в сообществе Go.
