Отличная цель! Go (Golang) — прекрасный язык с лаконичным синтаксисом, но он требует глубокого понимания работы с памятью, указателями, интерфейсами и системой типов. Ниже представлен подробный план из **110 упражнений**, разбитых по темам в порядке возрастания сложности. Это обеспечит вам интенсивную и всестороннюю тренировку от самых основ до продвинутых концепций.

### Тема 1: Пакеты, модули, компиляция и запуск из консоли
1. Создайте файл `main.go`, напишите простейшую программу "Hello, World!" и запустите её командой `go run`.
2. Инициализируйте новый модуль в пустой папке с помощью `go mod init example.com/myproject`.
3. Скомпилируйте вашу программу в исполняемый файл с помощью `go build` и запустите полученный бинарник из консоли.
4. Используйте флаг `-o` при компиляции, чтобы задать кастомное имя для исполняемого файла.
5. Создайте второй файл в той же папке с тем же `package main` и разнесите логику между двумя файлами. Скомпилируйте проект.
6. Проверьте версию Go, установленную в системе, используя команду `go version`.
7. Выведите информацию о переменных окружения Go с помощью `go env` и найдите пути к `GOPATH` и `GOROOT`.
8. Используйте команду `go fmt` на файле с намеренно плохим форматированием кода и проанализируйте результат.
9. Скомпилируйте проект для другой операционной системы (например, Linux из Windows), используя переменные окружения `GOOS` и `GOARCH`.
10. Запустите статический анализатор кода с помощью `go vet` на вашем проекте и исправьте найденные предупреждения.

### Тема 2: Пакет fmt и консольный ввод/вывод
11. Выведите на экран несколько переменных разных типов в одной строке, используя `fmt.Println` и разделители.
12. Используйте `fmt.Printf` для вывода целого числа в двоичном, восьмеричном и шестнадцатеричном форматах.
13. Выведите число с плавающей точкой с округлением до двух знаков после запятой с помощью `fmt.Printf`.
14. Считайте строку или число из консоли с помощью `fmt.Scan` и выведите результат обратно.
15. Считайте строку, содержащую пробелы, с помощью `bufio.NewReader` и `os.Stdin.ReadString`.
16. Используйте `fmt.Sscanf` для парсинга строки формата "Имя, возраст, рост" в соответствующие переменные.
17. Выведите текущее время в кастомном формате с помощью `fmt.Printf` и пакета `time`.
18. Напишите программу, которая запрашивает у пользователя два числа и выводит результат их сложения, корректно обрабатывая ошибки ввода с помощью `fmt.Scan`.
19. Используйте `fmt.Fprintf` для записи отформатированной строки в `os.Stderr`.
20. Реализуйте простой ASCII-art (например, песочные часы), выводя символы посимвольно с задержкой через `time.Sleep`.

### Тема 3: Базовые типы, переменные и константы
21. Объявите переменные всех базовых целочисленных типов (`int8`, `int16`, `int32`, `int64`, `uint8` и т.д.) и выведите их размер в байтах с помощью `unsafe.Sizeof`.
22. Создайте константу `Pi` и используйте её для вычисления площади круга заданного радиуса.
23. Попробуйте изменить значение константы во время выполнения программы и изучите ошибку компилятора.
24. Объявите неименованную константу (blank identifier `_`) в блоке `const`.
25. Создайте блок `const` с `iota` для перечисления дней недели, месяцев или уровней логирования.
26. Выполните приведение типов (type casting): преобразуйте `float64` в `int`, `int` в `float64` и `string` в `[]byte`, а затем обратно.
27. Изучите переполнение целочисленных типов (integer overflow) на примере `uint8`, добавив единицу к максимальному значению.
28. Объявите переменные с использованием короткого объявления (`:=`) и изучите, в каких областях видимости оно работает.
29. Создайте переменную типа `rune` (алиас для `int32`), присвойте ей кириллический символ и выведите его как символ и как число.
30. Объявите переменную типа `complex128`, выполните базовые арифметические операции и выведите мнимую и действительную части.
31. Создайте строку с эмодзи и выведите её длину в байтах (`len`) и количество символов (через конвертацию в `[]rune`).
32. Используйте побитовые операторы (`&`, `|`, `^`, `<<`, `>>`) над переменными типа `uint8`.
33. Создайте переменную-указатель, не инициализируйте её и выведите её значение по умолчанию (`nil`).
34. Напишите программу, которая меняет местами значения двух переменных без использования третьей (через множественное присваивание `a, b = b, a`).
35. Исследуйте разницу между одинарными и двойными кавычками при объявлении строк и символов (`string` vs `rune`).

### Тема 4: Функции: объявление, вызов и базовое использование
36. Напишите функцию, которая принимает два числа и возвращает их сумму, разность, произведение и частное (множественный возврат).

38. Напишите функцию, которая возвращает ошибку, если делитель равен нулю, и корректно обработайте её в `main`.
39. Создайте вариативную функцию (variadic function), принимающую произвольное количество чисел и возвращающую их среднее арифметическое.
40. Используйте оператор `...` для передачи слайса в вариативную функцию.
41. Напишите функцию, которая принимает строку и возвращает её реверс (учитывая Unicode-символы, а не просто байты).
42. Создайте функцию, которая принимает возраст и возвращает две булевы переменные: `isAdult` и `isSenior`.
43. Напишите функцию `swap`, которая меняет местами две строки и возвращает их.
44. Создайте функцию, которая генерирует последовательность Фибоначчи до N-го элемента и возвращает её в виде слайса.

### Тема 5: Функции: продвинутые возможности
46. Объявите анонимную функцию и немедленно её вызовите (IIFE).
47. Создайте замыкание (closure) — функцию, которая возвращает другую функцию, подсчитывающую количество своих вызовов.
48. Напишите функцию-генератор последовательности четных чисел с использованием замыкания.
49. Используйте ключевое слово `defer` для отложенного вывода сообщения "Программа завершена" в конце функции `main`.
50. Создайте три `defer`-вызова подряд и изучите порядок их выполнения (LIFO).
51. Напишите функцию, которая открывает файл (эмулируя), и используйте `defer` для гарантированного закрытия файла.
52. Используйте `panic` для прерывания выполнения программы при возникновении критической ошибки (например, деление на ноль).
53. Напишите функцию, которая использует `defer` и `recover` для перехвата `panic` и возвращения ошибки вместо падения программы.
54. Передайте функцию как аргумент в другую функцию (функция высшего порядка), например, для применения математической операции к числу.
55. Создайте тип `type MathFunc func(int, int) int` и напишите функции, которые принимают этот тип в качестве параметра.

### Тема 6: Указатели и работа с памятью
56. Создайте переменную, получите её адрес с помощью `&`, сохраните его в указатель и выведите значение указателя и значение по адресу (`*`).
57. Напишите функцию, которая принимает указатель на `int` и увеличивает его значение на 10.
58. Создайте указатель на указатель (`**int`), измените значение оригинальной переменной через двойное разыменование.
59. Напишите функцию `newInt()`, которая выделяет память под `int` с помощью `new`, записывает туда значение и возвращает указатель.
60. Сравните работу оператора `new` и взятия адреса от литерала `&struct{}` для создания указателей на структуры.
61. Создайте массив, получите указатель на него и попробуйте изменить элементы через указатель.
62. Напишите функцию, которая принимает два указателя на числа и меняет местами значения, на которые они указывают.
63. Создайте структуру `User` с полями `Name` и `Age`. Создайте указатель на неё и измените поля, используя как оператор `.`, так и разыменование `(*u).Name`.
64. Напишите функцию, которая возвращает указатель на локальную переменную функции. Убедитесь, что Go корректно обрабатывает это (escape analysis).
65. Изучите, как работает `nil`-указатель: создайте указатель на структуру, не инициализируйте его и попробуйте обратиться к полю (поймайте panic).

### Тема 7: Передача аргументов: по значению vs по ссылке
66. Напишите функцию, принимающую структуру по значению, и измените её поле. Убедитесь, что оригинал не изменился.
67. Напишите функцию, принимающую указатель на структуру, и измените её поле. Убедитесь, что оригинал изменился.
68. Передайте слайс в функцию, добавьте туда элемент с помощью `append` и проверьте, изменился ли оригинальный слайс. Объясните результат.
69. Передайте слайс в функцию и измените существующий элемент по индексу. Объясните разницу с предыдущим пунктом.
70. Передайте мапу (`map`) в функцию, добавьте новую пару ключ-значение и проверьте оригинал. Объясните, почему мапы ведут себя как ссылочные типы.
71. Передайте строку в функцию, "измените" её (создайте новую) и верните. Объясните неизменяемость (immutability) строк в Go.
72. Напишите функцию, которая принимает интерфейс и выводит его динамический тип и значение.
73. Создайте кастомный тип на основе `int`. Передайте его в функцию по значению и по ссылке, изучите разницу.
74. Напишите функцию, которая принимает функцию (callback) по значению и вызывает её. Является ли функция ссылочным типом?
75. Создайте канал (`chan int`), передайте его в функцию и отправьте туда данные. Проверьте получение в главной горутине.

### Тема 8: Каверзные случаи передачи аргументов и указателей

77. Создайте структуру, содержащую слайс. Передайте структуру по значению, а затем измените элемент слайса внутри переданной структуры. Объясните, почему оригинальный слайс изменился.
78. Создайте структуру с указателем на другую структуру. Передайте её по значению и измените поле вложенной структуры через указатель.
79. Создайте цикл `for`, в котором создается горутина, принимающая переменную цикла по ссылке (особенно актуально для версий Go до 1.22). Изучите классическую проблему замыкания и указателей.

81. Напишите функцию, которая принимает `interface{}` и указатель на интерфейс. Попытайтесь изменить значение через указатель на интерфейс и поймите, почему это антипаттерн.
82. Создайте структуру `Node` (связанный список), содержащую указатель на саму себя. Создайте кольцо из 3 узлов и напишите функцию, которая обходит его.
83. Передайте в функцию указатель на массив (не на слайс!). Измените элементы. Как это отличается от передачи слайса?
84. Напишите функцию, принимающую `*[]int` (указатель на слайс). Реализуйте добавление элемента так, чтобы оригинальный слайс гарантированно обновился даже при реаллокации базового массива.
85. Создайте структуру с приватными (неэкспортируемыми) полями. Попробуйте передать её по указателю в другой пакет и изменить поля. (Убедитесь, что компилятор выдаст ошибку).

### Тема 9: Работа с текстовыми файлами

91. Напишите скрипт, который подсчитывает количество слов, строк и символов в большом текстовом файле, не загружая его целиком в память.
