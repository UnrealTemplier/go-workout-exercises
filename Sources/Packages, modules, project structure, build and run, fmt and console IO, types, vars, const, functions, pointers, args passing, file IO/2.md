### 1. Установка, компиляция, модули и пакет main (основы)
1. Установите Go, настройте окружение (`GOROOT`, `GOPATH`, `PATH`), проверьте командой `go version`.
2. Напишите файл `main.go` с `package main` и `func main()`, выводящий `Hello, World!`. Запустите через `go run main.go`.
3. Скомпилируйте ту же программу командой `go build` и запустите полученный бинарник.
4. Установите программу в `$GOPATH/bin` с помощью `go install`, проверьте её вызов из любого места.
5. Инициализируйте модуль: `go mod init hello`. Изучите содержимое `go.mod`.
6. Добавьте внешнюю зависимость, например `github.com/fatih/color`, выполните `go get` и используйте её для цветного вывода строки.
7. Создайте в проекте подкаталог `mypkg` с файлом `helper.go` (пакет `mypkg`). Экспортируйте из него функцию и вызовите её из `main`.
8. Выполните `go fmt` и `go vet` для своего кода, исправьте все замечания.
9. Соберите кросс-компиляцией бинарники для Windows и Linux с помощью `GOOS` и `GOARCH`.
10. Напишите программу, читающую аргументы командной строки через `os.Args` и выводящую их количество и значения.
