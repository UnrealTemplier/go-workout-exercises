98. **Defer для файлов:** Перепиши упр. 96 и 97 так, чтобы функция `Close()` вызывалась через `defer` сразу после успешной проверки на ошибку открытия (`if err != nil`).
99. **Чтение по строкам:** Создай большой текстовый файл (несколько абзацев). Используй `bufio.Scanner`, чтобы считывать и выводить файл строго по одной строке (чтобы экономить оперативную память).
100. **Запись с дозаписью (Append):** Используй `os.OpenFile` с флагами `os.O_APPEND | os.O_WRONLY | os.O_CREATE`. Добавь новую строку в конец существующего файла.
101. **Чтение по кускам (Chunks):** Открой файл и читай его порциями ровно по 16 байт в цикле, используя метод `file.Read(buf)` до достижения `io.EOF`.

103. **Права доступа (Chmod):** Создай скрипт (например, файл `script.sh` с текстом `echo "hello"`). Используй `os.Chmod`, чтобы выдать ему права на исполнение (`0755`).
104. **Буферизированная запись:** Для быстрой записи большого количества строк используй `bufio.NewWriter`. Напиши 1000 строк в файл через него и обязательно вызови `Flush()` в конце, чтобы сбросить буфер на диск.

### Как с этим работать?
1. Создай на диске папку `go-workout`.
2. Для каждого упражнения (или блока) создавай отдельную директорию (например, `ex001_hello`, `ex076_pointers_basics`).
3. Кодь руками. Не копипасть. Если застрял — гугли официальную документацию (`pkg.go.dev` — твой лучший друг).
4. Обязательно "играй" с кодом. Если в упражнении сказано сделать X, сделай X, а потом сломай его и посмотри на ошибки компилятора — это самый ценный опыт.

Успехов в освоении Go! Это длинный, но очень увлекательный путь.
