Привет! Отличный настрой. Go — прекрасный язык, и интенсивная практика — лучший способ его освоить. 

Я составил для тебя **135 упражнений**, разбитых на 8 логических блоков. Сложность возрастает от простейших команд к каверзным кейсам с указателями и работе с файлами. 

Некоторые упражнения помечены как **[Высокая сложность]** или **[Каверзный кейс]** — именно они помогут тебе подготовиться к собеседованиям и реальным production-задачам.

### Блок 1: Запуск, сборка и базовая структура (Пакет `main`)
*Цель: Научиться управлять жизненным циклом программы через консоль, понимать структуру Go-файла.*

1. Установи Go (если еще не установлен). Выведи версию Go в консоль с помощью команды `go version`.
2. Создай папку проекта. Инициализируй в ней модуль с помощью `go mod init hello`.
3. Создай файл `main.go`. Напиши минимальную программу, которая выводит "Hello, World!".
4. Запусти программу с помощью `go run main.go`.
5. Скомпилируй программу в бинарный файл с помощью `go build`. Запусти полученный исполняемый файл напрямую из консоли.
6. Используй команду `go build -o myapp` для задания кастомного имени бинарнику. Запусти его.
7. Установи программу в системный `$GOPATH/bin` с помощью `go install`. Проверь, что она запускается из любой директории.
8. Отформатируй свой код с помощью `go fmt ./...`.
9. Проверь свой код на ошибки и неправильные паттерны с помощью `go vet ./...`.
10. Напиши программу, в которой будет функция `init()`, выводящая "Init started", и функция `main()`, выводящая "Main started". Проверь порядок вызова.
11. Создай два файла в одном пакете `main`: `main.go` и `utils.go`. В `utils.go` напиши функцию `SayHi()`, а в `main.go` вызови её. Убедись, что `go build` работает.
12. Попробуй объявить две функции `main` в разных файлах одного пакета. Посмотри на ошибку компиляции.
13. Изучи флаг `-race`. Напиши простейшую программу с горутинами (можно подсмотреть в инете) и запусти её с флагом `go run -race main.go`.
