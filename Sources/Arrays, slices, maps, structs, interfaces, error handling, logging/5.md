### Блок 13. Обработка ошибок (Error Handling) (201–212)
В Go нет `try/catch`. Ошибки — это обычные значения (реализующие интерфейс `error`).

201. **Базовые ошибки:** Используй `errors.New("bad input")` и `fmt.Errorf("user %s not found", name)` для создания простых ошибок.
202. **Кастомная ошибка:** Создай структуру `AppError` с полями `Code int` и `Message string`. Реализуй для неё метод `Error() string`. Верни её из функции.
203. **Sentinel Errors (Маркерные ошибки):** Объяви на уровне пакета `var ErrNotFound = errors.New("not found")`. Верни её из функции. В `main` сравни результат строго: `if err == ErrNotFound`.
204. **Обертывание (Wrapping):** При получении ошибки в функции (например, от базы данных), не возвращай её как есть. Оберни её: `return fmt.Errorf("failed to get user: %w", err)`.
205. **Распаковка `errors.Is`:** Получив обернутую ошибку из упр. 204, используй `errors.Is(err, ErrNotFound)`, чтобы проверить, есть ли в цепочке обертываний наша маркерная ошибка. (Простое `==` тут уже не сработает).
206. **Извлечение типа `errors.As`:** Оберни свою структуру `AppError` (из упр. 202) через `%w`. В `main` используй `errors.As(err, &myAppErr)`, чтобы достать её из обертки и прочитать конкретный HTTP `Code`.
207. **Множественные ошибки (Join):** В цикле валидации данных у тебя накопилось 3 разных ошибки. Используй `errors.Join(err1, err2, err3)` (Go 1.20+), чтобы склеить их в одну ошибку, и выведи её.
208. **Паника vs Ошибка:** Напиши пакет `config`. Сделай функцию `LoadConfig() error` (которая читает файл и возвращает ошибку, если файла нет) и функцию `MustLoadConfig()`, которая вызывает `LoadConfig` и если есть ошибка — делает `panic()`. Это классический паттерн "Must".
209. **Игнорирование ошибок:** Вызови `fmt.Println` (он возвращает кол-во записанных байт и ошибку). Проигнорируй возврат с помощью `_, _ = fmt.Println(...)`. Пойми, когда это допустимо, а когда — преступление.
210. **Отложенный Recover:** Напиши функцию, которая может запаниковать (например, деление на 0). В начале функции добавь `defer func() { if r := recover(); r != nil { fmt.Println("Спасены от:", r) } }()`.
211. **Централизованный хэндлер:** Напиши функцию-роутер, которая вызывает 3 другие функции (которые могут вернуть ошибки). Если любая из них возвращает ошибку, роутер логирует её и возвращает "HTTP 500", не дублируя код обработки логов каждый раз.
212. **Ошибки с контекстом:** Напиши функцию парсинга числа из строки. Если возникает ошибка, она должна возвращать ошибку, в которой сказано: "ошибка в функции ParseData на строке N: [оригинальная ошибка]".

222. **slog Группы:** Используй `slog.Group("db", slog.String("host", "localhost"), slog.Int("port", 5432))` внутри вызова `slog.Info`, чтобы сгруппировать поля в JSON-логе под одним ключом `"db": {...}`.
