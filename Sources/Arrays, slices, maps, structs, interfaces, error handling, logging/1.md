### 18. Слайсы — создание, len, cap, underlying array

**Упражнение 6.9.** Создай слайс тремя способами: `[]int{1,2,3}`, `make([]int, 5)`, `make([]int, 5, 10)`. Для каждого выведи `len` и `cap`. Объясни разницу.

**Упражнение 6.10.** Создай слайс `s := make([]int, 3, 5)`. Заполни первые 3 элемента. Сделай `s = s[:5]`. Что произойдёт? Покажи, что можно "расширить" слайс в пределах `cap`, и новые элементы будут нулевыми.

**Упражнение 6.11.** Создай слайс `s := []int{1,2,3,4,5}`. Сделай `s2 := s[1:3]`. Выведи `len(s2)`, `cap(s2)`. Объясни, почему `cap` равен 4, а не 2 (capacity отсчитывается от начала слайса до конца underlying array).

**Упражнение 6.12.** Используй **full slice expression** `s[low:high:max]`: `s := make([]int, 0, 10); s = append(s, 1,2,3,4,5); s2 := s[1:3:3]`. Покажи, что `cap(s2)` ограничен третьим аргументом. Зачем это нужно?

### 19. Слайсы — каверзные случаи и манипуляции

**Упражнение 6.15.** Создай слайс `s := []int{1,2,3}` с `len == cap`. Передай в функцию `AppendAndModify(s []int)`. Внутри: `s = append(s, 4)` и `s[0] = 999`. Верни `s`. В `main` проверь: `s[0]` оригинала изменился? Почему нет? (Реаллокация!)

**Упражнение 6.16.** Создай слайс `s := make([]int, 3, 10)` (cap > len). Передай в ту же функцию. Теперь `s[0]` оригинала изменился? Почему? (Нет реаллокации, shared array.) Это ключевое упражнение — разберись досконально.

**Упражнение 6.17.** Напиши функцию `DeleteByIndex(s []int, i int) []int`, которая удаляет элемент по индексу через `append(s[:i], s[i+1:]...)`. Покажи, что underlying array остаётся тем же (элементы сдвигаются, но память не освобождается).

**Упражнение 6.18.** Напиши функцию `InsertAt(s []int, index int, value int) []int`, которая вставляет элемент в середину. Сделай через `append(s[:index], append([]int{value}, s[index:]...)...)`. **Упражнение 6.19.** Используй `copy(dst, src)` для копирования слайса. Покажи, что `copy` корректно обрабатывает **перекрывающиеся** диапазоны (overlapping slices). Например, скопируй `s[2:]` в `s[1:]` для сдвига элементов влево.

**Упражнение 6.26.** Напиши функцию `ChunkSlice(s []int, size int) [][]int`, которая разбивает слайс на подслайсы заданного размера. Обрати внимание: подслайсы **делят** underlying array с оригиналом! Изменение в chunk изменит оригинал.

### Ключевые моменты для осознанного прохождения:

1. **Слайсы** — самая "коварная" тема в Go. Обязательно разберись с `append`, реаллокацией, shared underlying array и `range` с копированием значения. Упражнения 6.15–6.17 — критически важны.

2. **Мапы** — запомни: `var m map[T]V` — nil, чтение безопасно, запись паникует. Всегда используй `make` или литерал перед записью.

3. **Структуры** — pointer receiver vs value receiver — фундаментальное различие. Встраивание (embedding) — мощная фича, но следи за конфликтами имён.

4. **Интерфейсы** — пойми, что интерфейс — это `(type, value)`. Nil interface ≠ interface с nil-указателем внутри. Это ловушка №1 для новичков в Go.

5. **Ошибки** — в Go принят explicit error checking. `if err != nil` — не стыдно, а идиома. Изучи `%w`, `errors.Is`, `errors.As` — это современный стандарт.

6. **Логирование** — переходи на `log/slog` для новых проектов. Структурированные логи (JSON) — must have для production.
