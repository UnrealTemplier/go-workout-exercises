# Мапы (Maps)

В этом файле собраны уникальные упражнения по теме **"Мапы (Maps)"**, отсортированные по возрастанию сложности.

---

1. **Чтение несуществующего ключа**: Запроси из нормальной мапы ключ, которого там нет. Убедись, что программа не падает, а возвращает *zero value* (ноль для `int`).

2. Объяви `var m map[string]int` (nil map). Прочитай значение по ключу: `v := m["key"]`. Покажи, что не паникует, возвращает zero value (`0`). Затем попробуй записать: `m["key"] = 1` — получи панику **assignment to entry in nil map**. Объясни, почему чтение безопасно, а запись — нет.

3. Создай мапу-литерал: `map[string]int{"one": 1, "two": 2, "three": 3}`. Пройди по ней `for k, v := range`.

4. **Идиома Comma Ok**: Как отличить, в мапе реально лежит ноль, или ключа просто нет? Запроси значение как `val, ok := m["key"]` и выведи `ok`.

5. Напиши функцию `SafeGet(m map[string]int, key string) (int, bool)`, использующую **comma ok** идиому: `v, ok := m[key]`. Верни значение и флаг наличия.

6. **Безопасное удаление**: Используй функцию `delete(m, "key")`. Попробуй удалить ключ, которого нет в мапе (убедись, что это не вызывает ошибок).

7. Создайте мапу `map[string]int`, добавьте в нее 3 пары ключ-значение и выведите их.

8. **Вложенные мапы**: Создай `map[string]map[string]int`. Добавь значение. Не забудь, что внутреннюю мапу тоже нужно инициализировать через `make`, иначе будет паника.

9. Попробуйте обратиться к несуществующему ключу в мапе. Какое значение "по умолчанию" вернется?

10. **Структура как ключ**: Создай структуру `Point{X, Y int}`. Используй её в качестве ключа для мапы. (В Go ключом может быть любой тип, для которого определена операция `==`).

11. Создай мапу `map[string][]int` (значение — слайс). Добавь элементы: `m["nums"] = append(m["nums"], 1)`. Покажи, что если `append` вызывает реаллокацию, мапа **не увидит** новые элементы (потому что слайс в мапе — это struct data, и она не обновляется автоматически). Исправь через переприсваивание.

12. Попробуй сравнить две мапы через `==` (кроме `nil`). Получи ошибку компиляции. Объясни, почему мапы **не comparable** в Go.

13. Создай мапу, хранящую частоту слов в строке: `map[string]int`. Посчитай слова и выведи результат.

14. Создай мапу с ключом-структурой: `map[Point]string`, где `Point struct{ X, Y int }`. Покажи, что struct **comparable** может быть ключом. Добавь точки и ищи по координатам.

15. Постройте частотный словарь: на вход строка, на выход `map[rune]int`.

16. **Указатель как ключ**: Измени тип ключа на `*Point`. Создай две разные переменные с одинаковыми координатами `X` и `Y`. Запиши значение по первому указателю, а попытайся прочитать по второму. Изучи, почему вернется 0 (адреса-то разные!).

17. Реализуй **множество (Set)** через `map[string]struct{}`. Покажи, что `struct{}` занимает 0 байт. Реализуй методы: `Add`, `Remove`, `Contains`, `Union`, `Intersection`.

18. Удалите элемент из мапы с помощью `delete`. Что произойдет (упадет ли программа), если попытаться удалить несуществующий ключ?

19. Удали элемент через `delete(m, "key")`. Покажи, что удаление несуществующего ключа **не паникует** и не возвращает ошибку.

20. **Мапа с функциями (Command Dispatcher)**: Создай `map[string]func(int, int) int`. Положи туда ключи "add", "sub", "mul" и соответствующие анонимные функции. Вызови нужную функцию по строковому ключу.

21. Создай мапу функций: `map[string]func(int, int) int`. Заполни операциями `add`, `sub`, `mul`, `div`. Используй как калькулятор: пользователь вводит операцию, программа вызывает соответствующую функцию.

22. **Паника при инициализации**: Объявите мапу `var m map[string]int` без инициализации. Попробуйте прочитать ключ — что вернет Go? Теперь попробуйте записать значение `m["key"] = 1`. Зафиксируйте панику. Инициализируйте мапу с помощью `make` и исправьте ошибку.

23. Инвертируйте map `[string]int` в `[int]string`, проверьте на коллизии.

24. **[Каверзный кейс]**: Объяви `var m map[string]int`. Попробуй сделать `m["a"] = 1` (поймай панику записи в nil-мапу). Исправь с помощью `make`.

25. Используйте идиому `value, ok := myMap[key]` для безопасной проверки наличия ключа перед его использованием.

27. **Подсчет частоты слов**: Напиши функцию, которая принимает строку текста (с пробелами), разбивает её на слова (пакет `strings`) и с помощью мапы подсчитывает, сколько раз встретилось каждое слово.

28. Пройди `range` по мапе и попробуй изменить значение через переменную цикла: `for k, v := range m { v++ }`. Покажи, что мапа не изменилась. Сделай правильно: `for k := range m { m[k]++ }`.

29. **Запятая-ок (Comma-ok idiom)**: Создайте мапу соответствия стран и их столиц. Напишите код, который проверяет наличие города в мапе. Продемонстрируйте разницу между получением дефолтного значения для несуществующего ключа и реальной проверкой через `val, ok := m[key]`.

30. Попробуй прочитать значение по несуществующему ключу. Выведи результат (должен быть нулевым значением типа).

31. Отсортируйте ключи map и выведите значения в отсортированном порядке.

32. **Очистка мапы**: Используй встроенную функцию `clear(m)` (появилась в Go 1.21), чтобы удалить все элементы из мапы.

33. Напиши функцию `MapKeys(m map[string]int) []string`, возвращающую слайс ключей. Запусти несколько раз — покажи, что **порядок итерации не детерминирован**.

35. Напиши функцию `ClearMap(m map[string]int)`, удаляющую все элементы. Реализуй через `for k := range m { delete(m, k) }`. В Go 1.21+ используй встроенную `clear(m)` и сравни.

37. **Fatal error: concurrent map writes**: Создай мапу. В цикле запусти 100 горутин (добавь слово `go` перед вызовом анонимной функции `go func(){ m["a"] = 1 }()`), которые одновременно пишут в мапу. Поймай аварийное завершение программы. (Мапы в Go не потокобезопасны на запись!).
